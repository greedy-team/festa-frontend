# 서비스 타겟 환경 및 브라우저 지원 범위

FESTA가 어떤 화면 크기와 브라우저를 기준으로 만들어졌는지 정리한 문서입니다.

## 1. 타겟 화면 크기 — 데스크톱 우선

| 환경 | 폭 | 상태 |
|---|---|---|
| Desktop | 1440px | 기준 캔버스 |
| Laptop | 1280px | 대응됨 |
| Tablet | 768px | 예상 레이아웃만, 미확정 |
| Mobile | — | 이번 범위 밖(추후 제작 예정) |

시안(Figma)이 1440px 기준으로 그려져 있어 이 폭을 기준 캔버스로 삼았습니다. 실제 구현은
픽셀 값을 그대로 박지 않고 유동(반응형)으로 풀었고, 히어로 캐러셀은 Tailwind 기본
브레이크포인트를 기준으로 1장(~639px) / 2장(640~1023px) / 4장(1024px~)으로 나뉩니다.
모바일 레이아웃은 아직 설계되지 않은 상태라 이번 범위에서 뺐습니다.

## 2. 지원 브라우저

`package.json`의 `browserslist`로 명시적으로 정의했습니다.

| 브라우저 | 최소 버전 | 비고 |
|---|---|---|
| Chrome | 111+ | Next.js 기본값 |
| Edge | 111+ | Next.js 기본값 |
| Firefox | 111+ | Next.js 기본값 |
| Safari | 16.4+ | Next.js 기본값 |
| 삼성인터넷 | 19+ | 별도로 추가 |
| 오페라 | 97+ | 별도로 추가 |

**IE는 지원하지 않습니다.** Next.js 자체가 폴리필을 제공하지 않아요.

## 3. 어떻게 정했는지

Next.js 16은 기본적으로 `browserslist`의 "baseline widely available" 기준(Chrome/Edge/
Firefox 111+, Safari 16.4+)으로 빌드 타겟을 잡습니다. 문제는 이 기본값에 **삼성인터넷과
오페라가 아예 빠져 있다는 것**입니다. 둘 다 Chromium 기반이라 "Chrome이 커버하겠지"라고
오해하기 쉽지만, 브라우저 호환성 데이터베이스(caniuse-lite)는 별도 브라우저로 취급합니다.

국내 서비스, 특히 안드로이드 사용자 비중이 큰 서비스에서는 삼성인터넷이 실제로 상당한
비중을 차지합니다. 그래서 두 브라우저를 `browserslist`에 명시적으로 추가했습니다.

최소 버전은 임의로 정하지 않고 아래 기준으로 골랐습니다.

- **삼성인터넷 19+**: caniuse-lite 데이터 기준 현재 최신이 30이고, 19는 2022년 중반 이후
  버전 — 나머지 4개 브라우저가 커버하는 기간(약 3년)과 비슷한 폭을 맞췄습니다.
- **오페라 97+**: 위키백과에서 확인한 Opera 83(2022-01-19 출시)·Opera 100(2023-06-20 출시)
  출시일 사이를 보간해, Chrome 111(2023년 3월)과 비슷한 시기의 버전을 골랐습니다. 정확한
  릴리스 노트 대조는 아니라 추정값이라는 점은 남겨둡니다.

## 4. 실제 설정

```json
// package.json
"browserslist": [
  "chrome >= 111",
  "edge >= 111",
  "firefox >= 111",
  "safari >= 16.4",
  "samsung >= 19",
  "opera >= 97"
]
```

이 설정은 Next.js가 SWC로 코드를 컴파일할 때 어떤 문법까지 그대로 두고 어떤 문법을
트랜스파일할지 결정하는 빌드 타겟입니다. 화면 동작 자체를 바꾸는 설정은 아닙니다.

## 5. 예상 질문

**"왜 이 브라우저들이에요? 근거가 있어요?"**
Next.js 공식 문서를 직접 조회해서 기본 지원 범위(Chrome/Edge/Firefox/Safari 최신)를
확인했고, 여기에 국내에서 실제로 많이 쓰이는데 기본값에서 빠져 있던 삼성인터넷·오페라를
추가했습니다. 최소 버전도 브라우저별 실제 출시일을 확인해서 다른 브라우저들과 비슷한
시기로 맞췄습니다.

**"모바일은 왜 지원 안 해요?"**
데스크톱 우선으로 먼저 만들었고, 모바일 레이아웃은 처음부터 이번 범위 밖으로 뒀습니다.

**"IE는요?"**
지원하지 않습니다. Next.js 자체가 최신 브라우저만 대상으로 하고, 별도 폴리필을 추가하지
않았습니다.
