## 본문

## 🔍 현재 문제점

- 축제 전체 페이지(`/festivals`) 상단의 검색창이 표시만 되고 아무 동작을 하지 않는다.
- 실제 동작: 검색창에 입력해도 포커스가 잡히지 않고, 목록이 그대로 전체 목록이다.
- 예상 동작: 축제 이름을 입력해 제출하면 그 이름으로 목록이 좁혀진다. 아티스트 전체 페이지의 검색과 같은 방식으로 동작해야 한다.

## 🔄 재현 방법

1. 축제 전체 페이지로 이동한다.
2. 상단 검색창을 클릭하고 축제 이름 일부를 입력한다.
3. 입력이 되지 않고, 목록도 좁혀지지 않는 것을 확인한다.

## 💡 해결 방안

- 검색창을 표시 전용 요소가 아니라 실제 검색 입력으로 바꾸고, 입력한 검색어를 목록 API로 전달한다.
- 목록 API는 이미 이름 검색어(`q`)를 받도록 되어 있어 프론트에서 전달만 하면 된다.
- 검색해도 걸어둔 정렬은 유지하고, 검색 시 첫 페이지로 돌아간다. 검색 결과가 없을 때는 그에 맞는 안내 문구를 보여준다.

## 📸 참고 자료

- 아티스트 전체 페이지(`/artists`)의 이름 검색이 같은 성격의 선행 사례다.
