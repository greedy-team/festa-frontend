## 제목

🔧 [설정][CI] README 버전 업데이트의 보호 브랜치 직접 푸시 제거

## 본문

## 🔍 현재 문제점

- 릴리스 준비 과정에서 README 버전 정보가 이미 갱신되지만, main 반영 후 별도 자동화가 README를 다시 수정합니다.
- 이 추가 변경을 main에 직접 푸시하면서 필수 상태 검사 규칙에 막혀 버전 업데이트 작업이 실패로 표시됩니다.

## 💡 해결 방안 / 제안 기능

- README 버전 정보는 릴리스 준비 PR에서 한 번만 갱신하고 검증합니다.
- main 반영 후에는 버전 태그와 배포만 수행되도록 릴리스 흐름을 정리합니다.
- 영향 범위: README 버전 표기와 릴리스 자동화이며 제품 동작에는 영향이 없습니다.
