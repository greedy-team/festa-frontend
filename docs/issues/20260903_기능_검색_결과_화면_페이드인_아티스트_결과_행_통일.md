## 본문

## 🔍 현재 문제점

- 통합 검색 결과 화면(/search)만 진입 페이드인이 없다. 축제·아티스트·주최 화면은 모두 nav나 링크로 들어올 때 부드럽게 나타나는데 검색 화면만 뚝 뜬다.
- 아티스트 검색 결과가 아직 이름 해시 색 + 이니셜 원형 아바타를 쓴다. 사진이 없는 자리를 색 배경으로 채우지 않기로 한 결정에 따라 아티스트 히어로와 목록에서는 이미 이 아바타를 걷어냈는데, 검색 결과만 반영되지 않았다.
- 아티스트 결과만 테두리 카드에 별도 버튼이 붙은 형태라, 같은 화면의 학교·축제 결과 행과 시각적으로 어긋난다.

## 💡 해결 방안 / 제안 기능

- 검색 결과 화면을 다른 사용자 화면과 같은 진입 페이드인으로 감싼다.
- 아티스트 결과에서 색 아바타를 제거한다.
- 아티스트 결과를 학교·축제 결과와 같은 행 형태로 통일한다. 이름·출연 횟수·최근 출연일을 텍스트로 보여주고 행 전체가 아티스트 상세로 이동하게 한다.
