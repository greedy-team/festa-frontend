## 제목

🚀 [기능개선][헤더] nav 메뉴(홈·축제·아티스트)에 hover 시 글씨 확대 효과 추가

## 본문

## 🔍 현재 문제점

- 데스크톱 헤더의 nav 메뉴(홈·축제·아티스트)는 hover 시 글자 색만 바뀐다. 마우스를 올렸을 때 어떤 항목을 가리키는지 시각 피드백이 약하다.
- 마우스를 올리면 글씨가 살짝 커지면서 반응하는 느낌을 주고 싶다.
- DESIGN.md의 상호작용 상태는 Default / Active / Hover(그림자만)만 정의돼 있어, nav 글씨 확대는 디자인 시스템에 없는 새 상호작용이다. 디자이너 검토가 필요하다.

## 💡 해결 방안 / 제안 기능

- nav 메뉴 항목에 hover 시 글씨가 살짝 커지는 효과를 준다. 확대 폭은 "살짝" 수준(과하지 않게).
- 글씨가 커질 때 옆 메뉴나 활성 밑줄이 밀리지 않아야 한다 — hover로 레이아웃이 흔들리면 안 된다.
- 모션 감소 설정(prefers-reduced-motion)에서는 확대·전환을 끈다. 기존 헤더 코드가 이미 같은 관례를 따른다.
- 적용 범위: 데스크톱 nav 3개 항목. 활성 메뉴에도 적용할지, 모바일 드롭다운 메뉴에도 적용할지는 작업 중 확인한다.
