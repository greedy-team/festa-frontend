## 제목

🚀 [기능개선][홈][검색][축제상세] 진행 중인 축제는 D-day를 D-DAY로 고정 표기

## 본문

## 🔍 현재 문제점

- 메인 홈 히어로·검색 결과 축제 행·축제 상세 히어로의 D-day는 축제 시작일 기준으로 계산된다. 이미 시작해서 진행 중인 축제는 "D+2"처럼 시작일로부터 지난 일수로 뜬다.
- "D+2"는 그 축제가 진행 중이라는 것과 무관해 보이는 숫자다. 사용자가 궁금한 것은 "오늘이 이 축제 날인가"다.
- DEC-0059(메인 화면 D-day 표기 결정)도 "이미 지난(시작한) 축제의 D-day를 어떻게 표기할지"를 미해결로 남겨둔 지점이다.

## 💡 해결 방안 / 제안 기능

- 진행 중인 축제는 시작일부터 종료일까지, 며칠째든 D-day를 "D-DAY"로 고정한다. 예: 09.09~09.11 축제는 09.09·09.10·09.11 세 날 모두 D-DAY.
- 아직 시작 전인 축제는 지금처럼 시작일 기준 D-day를 그대로 유지한다.
- 적용 범위: 메인 홈 히어로·검색 결과 축제 행·축제 상세 히어로, 셋 다 바꾼다. 같은 축제가 화면마다 다르게 보이면 안 된다.

## 🔧 작업 내용

- [ ] 진행 중인 축제의 D-day를 D-DAY로 고정하도록 변경 (홈 히어로 + 검색 결과 축제 행 + 축제 상세 히어로)
- [ ] 시작 전 축제는 기존 시작일 기준 표기가 그대로인지 확인
- [ ] 진행 중인 모든 날짜(시작일·가운데·종료일)에서 D-DAY로 뜨는지 확인
