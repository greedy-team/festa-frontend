## 제목

🚀 [기능개선][홈][검색] 진행 중인 축제는 D-day를 종료일 기준으로 표기

## 본문

## 🔍 현재 문제점

- 메인 홈 히어로와 검색 결과 축제 행의 D-day는 축제 시작일 기준으로 계산된다. 이미 시작해서 진행 중인 축제는 "D+2"처럼 시작일로부터 지난 일수로 뜬다.
- "D+2"는 그 축제가 언제 끝나는지와 무관한 숫자라 바로 와닿지 않는다. 사용자가 궁금한 것은 "이 축제가 며칠 남았는지"다.
- DEC-0059(메인 화면 D-day 표기 결정)도 "이미 지난(시작한) 축제의 D-day를 어떻게 표기할지"를 미해결로 남겨둔 지점이다.

## 💡 해결 방안 / 제안 기능

- 진행 중인 축제는 시작일이 아니라 종료일까지 남은 일수로 D-day를 표기한다. 예: 09.09~09.11 축제가 오늘 09.11이면 D-DAY, 09.10이면 D-1.
- 아직 시작 전인 축제는 지금처럼 시작일 기준 D-day를 그대로 유지한다.
- 적용 범위: 메인 홈 히어로와 검색 결과 축제 행, 둘 다 바꾼다. 같은 D-day 계산 함수를 공유하는 화면이라 — 같은 축제가 화면마다 다르게 보이면 안 된다.

## 🔧 작업 내용

- [ ] 진행 중인 축제의 D-day를 종료일 기준으로 계산하도록 변경 (홈 히어로 + 검색 결과 축제 행)
- [ ] 시작 전 축제는 기존 시작일 기준 표기가 그대로인지 확인
- [ ] 종료 당일(D-DAY) 표기 확인
