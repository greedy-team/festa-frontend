## 본문

## 📝 현재 문제점

- 헤더의 프로필 아이콘(인디고 원)과 푸터의 소셜 아이콘 3개는 로그인·SNS 연동이 없는 상태에서 빈 플레이스홀더로 계속 표시되고 있다.
- 393×852(아이폰 기준) 화면에서 헤더는 프로필 아이콘 때문에 여백이 빡빡하고, 푸터의 소셜 아이콘 3개는 "고객센터" 컬럼 아래로 떨어져 어색하게 줄바꿈된다.
- 푸터의 링크·copyright 텍스트(`text-label-regular`, 12px)가 모바일 화면에서 작게 읽힌다.

## 🛠️ 해결 방안 / 제안 기능

- 헤더 프로필 아이콘, 푸터 소셜 아이콘 3개를 완전히 제거한다 (아직 로그인·SNS 기능이 없어 대체 아이콘을 넣을 근거가 없다).
- 393px 기준 모바일 화면에서 헤더·푸터가 자연스럽게 보이도록 레이아웃을 확인·조정한다.
- 푸터의 작은 텍스트(링크, copyright)를 모바일에서만 13px로 키우고, 640px 이상(sm)에서는 기존 12px 토큰을 유지한다.

## ⚙️ 작업 내용

- `Header.tsx`: 프로필 아이콘 `<span>` 삭제
- `Footer.tsx`: 소셜 아이콘 3개 블록 삭제, 링크·copyright 텍스트에 모바일 전용 크기 적용
- 393×852 뷰포트에서 헤더·푸터 렌더 확인
