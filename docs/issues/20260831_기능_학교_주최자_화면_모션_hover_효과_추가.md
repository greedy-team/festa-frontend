## 제목

🚀 [기능개선][학교주최자] 학교 상세·축제 이력 화면에 진입 모션·hover 효과 추가

## 본문

## 🔍 현재 문제점

- 축제·아티스트 목록/상세 화면은 진입 시 페이드업 모션과 카드 hover 효과가 적용돼 있는데, 학교(주최자) 상세와 축제 이력 화면만 빠져 있어 화면 사이를 오갈 때 학교 화면만 정적으로 뚝 뜬다.
- 학교 상세의 다가오는 축제 카드, 축제 이력 카드, 자주 온 아티스트 카드에 hover 반응이 없어 클릭 가능한 요소로 보이지 않는다.
- ISS-0081(축제 목록·상세 진입 모션 추가)에서 공용 모션 컴포넌트를 만들 때 학교 화면은 범위에 포함되지 않았다.

## 💡 해결 방안 / 제안 기능

- 학교 상세 화면(`/hosts/[id]`)과 축제 이력 화면(`/hosts/[id]/history`) 전체를 다른 화면과 동일하게 진입 페이드업으로 감싼다.
- 학교 상세의 히어로 아래 섹션들은 스크롤 진입 시 한 번 더 페이드업되게 한다(축제 상세와 동일).
- 다가오는 축제 카드와 축제 이력 카드는 포스터 카드용 hover(살짝 확대 + 그림자)를, 자주 온 아티스트 카드는 살짝 떠오르는 그림자 hover를 적용한다.
- 히어로 자체에는 hover를 넣지 않는다(다른 히어로와 일관).
- 모두 기존 공용 컴포넌트·클래스를 재사용하므로 모션 감소(prefers-reduced-motion) 대응은 자동으로 유지된다.
