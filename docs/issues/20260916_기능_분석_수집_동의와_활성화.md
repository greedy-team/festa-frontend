## 제목

🚀 [기능요청][분석][개인정보] 분석 수집 동의와 GA4·Clarity 활성화

## 본문

## 🔍 현재 문제점

- #220에서 GA4·Clarity 연결을 준비하지만 방문자의 분석 동의·거부·철회 기능이 없다.
- 공개된 약관은 단순 방문을 개인정보 수집 동의로 취급하지 않으며, 선택적 처리 거부에도 기본 축제 정보 열람을 허용한다.
- 동의 기능과 수집 범위 검증 전에는 실제 방문 분석을 활성화할 수 없다.

## 💡 해결 방안 / 제안 기능

- 분석 목적·수집 항목을 안내하고 명시적으로 동의하거나 거부할 수 있도록 한다.
- 동의를 변경하거나 철회할 수 있고, 거부해도 기본 정보 탐색은 유지한다.
- 동의 상태와 공개 화면 범위에 맞춰 GA4·Clarity를 활성화한다.

- [ ] 동의·거부·철회 화면 및 선택 유지 기능 제공
