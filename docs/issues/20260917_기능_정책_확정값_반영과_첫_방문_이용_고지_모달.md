## 제목

🚀 [기능요청][정책][개인정보] 정책 확정값 반영과 첫 방문 이용 고지 모달

## 본문

## 🔍 현재 문제점

- 배포된 개인정보 처리방침·이용약관에 운영자명, 문의처, 보유기간, 국외 이전 내역 등 43개 항목이 "(항목명 확정 전)"으로 표시된다.
- 선택적 분석 도구 고지 항목이 비어 있어 #233에서 준비한 GA4·Clarity 수집을 운영에서 켤 수 없다.
- 로그인이 없어 약관과 처리방침이 서비스 이용에 적용된다는 사실을 방문자에게 알리는 접점이 없다.

## 💡 해결 방안 / 제안 기능

- 처리방침·약관의 미확정 항목을 실제 운영 정보로 채우고 시행일을 정한다.
- 첫 방문 시 서비스 이용에 약관과 처리방침이 적용됨을 한 번 안내하는 모달을 띄운다. 로그인이 없으므로 안내 확인 후 계속 이용하는 것을 약관 적용에 대한 확인으로 본다.
- 선택적 분석 수집은 이용 간주로 처리하지 않고 #233의 명시적 선택을 유지한다. 안내와 분석 선택은 한 화면에서 처리해 방문자에게 모달이 두 번 뜨지 않게 한다.
- 안내 문구와 정책 페이지 문구는 ux-writing 가이드를 따른다.

- [ ] 처리 근거·보유기간 항목(접속기록, 관리자 계정, 문의, 신고, 이용허락, 공개 출연정보) 반영
- [ ] 선택적 분석 도구 고지(도구·목적·항목·보유기간·거부 방법)와 쿠키 사용 내역 반영
- [ ] 처리위탁·제3자 제공·국외 이전 표 반영 (GA4·Clarity·포스터 저장소·지도 제공자)
