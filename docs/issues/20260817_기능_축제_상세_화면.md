## 본문

## 📝 현재 문제점

홈에 축제 카드가 떴지만 누를 곳이 없다. 이슈 #41이 히어로 "자세히 보기"의 목적지를 정하려고 열려 있는데, 목적지 화면 자체가 없어서 연결할 수가 없다.

`GET /festivals/{id}`는 MSW 목이 이미 응답한다. 주최 정보·D-day·포스터·day별 라인업·입장 정보·좌표까지 화면이 필요한 필드가 다 들어 있는데, 받아 그릴 화면이 없어서 안 쓰이고 있다.

또 `.claude/rules/DESIGN.md`(v3.0)는 화면 단위로 홈(06-D)만 적혀 있다. 이 화면이 쓸 조각(`day-card` 410×200, `badge-dday`, `bottom-cta-banner`)은 컴포넌트 시트에 있지만 화면 조립 구조는 문서에 없고 피그마에만 있다.

## 🛠️ 해결 방안 / 제안 기능

`/festivals/[id]` 경로를 만들고 `GET /festivals/{id}` 응답으로 네 영역을 그린다 — 히어로, 라인업, 정보, 오시는 길. 데이터는 홈과 같은 방식(서버 컴포넌트 fetch)으로 받는다.

같은 이슈에서 이 화면의 구성 요소와 배치 원칙을 DESIGN.md에 추가한다. 1440 좌표 레이아웃은 옮기지 않는다 — 시안의 픽셀은 비율과 위계의 근거이지 계약이 아니고, 세부는 피그마를 직접 본다.

## ⚙️ 작업 내용

1. 라우트 — `/festivals/[id]`. 축제 단건 조회 함수를 추가한다

2. 히어로 — 포스터, D-day, 축제명, 기간, 상태 뱃지, 주최 로고와 이름. 주최 이름은 주최 상세로 링크한다

3. 라인업 — `day-card`를 응답의 `lineup` 배열대로 day별로 반복한다. 미공개 아티스트는 원형과 이름의 대비를 낮춘다

4. 정보 — 입장 정보 3종(외부인 입장·티켓 형태·본인확인)을 칩으로 그린다. 영문 열거값을 한국어 문구로 옮기는 매핑을 만든다

5. 오시는 길 — 장소명, 주소, 외부 길찾기 링크. 지도가 들어갈 자리는 폴백 박스로 둔다

6. 없는 축제 — 404를 받으면 Next.js의 not-found로 넘긴다

7. DESIGN.md에 이 화면의 구성 요소와 배치 원칙을 범용 규칙으로 추가한다. 좌표 레이아웃은 옮기지 않는다. 새로 만든 공용 컴포넌트는 `/showcase`에 등재한다

## 📌 확정한 설계 결정

- **D-day는 서버가 준 `dday` 값을 그대로 쓴다.** 홈 히어로는 프론트가 직접 계산한다 — `/festivals/upcoming`이 명세에서 프론트 계산으로 지정된 예외 자리이기 때문이다. 이 엔드포인트는 서버가 계산해 내려주므로 다시 계산하지 않는다. 두 화면의 계산 주체가 다른 것이 현재로선 정상이다
- **`host.type`을 화면에 쓰지 않는다.** 목 응답에는 들어 있지만 확정된 ERD에는 없는 필드다. 주최 표기는 이름과 로고로만 한다
- **라인업 아티스트의 id는 이 응답의 `id`를 쓴다.** 같은 아티스트를 가리키는 필드 이름이 엔드포인트마다 `id`와 `artistId`로 갈려 있고 이슈 #40이 그것을 다룬다. 결론이 나면 그때 맞춘다
- **없는 축제 판별은 HTTP status로만 한다.** 응답 본문의 `errorCode`별 사용자 문구 정책이 아직 없고, 404는 status만으로 갈라진다. 코드별 문구가 정해지면 그때 응답 본문을 읽는다
- **미공개 아티스트의 자리를 비우지 않는다.** 응답이 `revealed: false`로 자리를 표시해 내려주므로 라인업 규모가 그대로 보인다. 아직 공개 안 된 것과 라인업이 작은 것은 사용자에게 다른 정보다
- **포스터가 없는 것을 정상 경로로 둔다.** 홈에서 쓴 방식(틴트를 먼저 깔고 이미지를 그 위에 얹어, 실패하면 이미지가 스스로 사라짐)을 그대로 쓴다

## 🚫 범위에서 빼는 것

- **지도 임베드.** 구글 맵을 쓰는 것은 확정됐지만 API 키와 결제 계정은 이 저장소 밖의 일이다. 별도 이슈로 뺐고, 이 화면은 그 자리에 폴백 박스를 남긴다
- 요약 시트. 카드를 누르면 요약을 거치지 않고 상세로 바로 오기로 확정됐다. `/festivals/{id}/summary`는 보류 상태다
- 공지와 교통편 안내. 약도·지하철·버스·주차 안내를 만들지 않기로 했고, 명세에서도 제거된 항목이다
- 분실물. 축제 기능 뒤로 미뤄진 범위다
- 광고 슬롯. 홈 외 화면의 광고 위치·크기 정책이 없다
- 축제 목록 화면. 별도 이슈다
- 화면 전환 연출. 카드에서 상세로 곧장 이동한다는 것만 정해져 있고 연출은 미정이다
