## 본문

## 🔍 현재 문제점

- 다가오는 축제가 0건인 시즌(방학 등)에 홈 히어로가 서비스 소개 문구와 바로가기 카드 3장을 보여준다.
- 바로가기 카드 3장(축제 라인업·아티스트·통합 검색)은 헤더 메뉴와 목적지가 겹친다. 같은 이동 경로를 한 화면에 두 번 그리는 셈이라, 콘텐츠 자리를 이동 수단이 차지하고 있다.
- 헤드라인이 서비스 슬로건이어서 지금 화면이 왜 비어 있는지를 설명하지 못한다. 이 화면에 온 사용자가 궁금해하는 것은 언제 다시 축제가 열리는지다.
- 안내 문구가 부정형 표현을 쓰고 있어 저장소 문구 규칙(해요체·긍정형)과 어긋난다.
- 배경이 단색 한 겹에 흐린 원 하나뿐이라 한쪽 구석만 밝고 나머지는 비어 보인다.

## 💡 해결 방안 / 제안 기능

- 바로가기 카드 3장을 걷어내고, 다음에 할 행동을 하나로 좁혀 제시한다.
- 배경을 히어로 패널이 쓰는 포스터 틴트 여러 가지가 섞인 형태로 바꾼다. 포스터 네 장이 있어야 할 자리가 지금은 비어 있다는 상태 자체를 배경으로 표현한다.
- 헤드라인과 안내 문구를 다시 쓴다. 화면이 비어 있는 이유와 그동안 할 수 있는 일을 담고, 문구 규칙(해요체·긍정형·능동형)을 따른다.
- 좁은 화면에서 제목이 어절 중간에서 끊기지 않게 줄바꿈을 다듬는다.
