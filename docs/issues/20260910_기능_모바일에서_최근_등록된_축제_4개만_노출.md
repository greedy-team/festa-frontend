## 제목

🚀 [기능개선][홈] 모바일에서 "최근 등록된 축제"를 4개만 노출

## 본문

## 🔍 현재 문제점

- 홈 "최근 등록된 축제" 섹션은 데스크톱·모바일 모두 동일하게 5개를 노출한다.
- 모바일은 2열 그리드라 5개가 2 + 2 + 1로 떨어지고, 마지막 행에 카드 한 장만 남는 고아 행이 생긴다.
- 좁은 화면에서 섹션이 정돈되지 않아 보이고 세로 스크롤도 그만큼 길어진다.
- 태블릿(3열)·데스크톱(5열)은 5개가 깔끔하게 떨어져 문제가 없다.

## 💡 해결 방안 / 제안 기능

- 모바일 뷰포트에서는 이 섹션을 4개까지만 노출해 2 x 2로 맞춘다.
- 태블릿·데스크톱(sm 이상)은 지금 그대로 5개를 유지한다.
- 노출 개수가 뷰포트에 따라 갈리므로 판정은 CSS 한 곳에서만 한다 — 서버가 화면 폭을 모르는 상태에서 JS로 폭을 재 개수를 자르지 않는다(히어로 패널 캐러셀에서 이미 겪은 함정). 5개를 받아 렌더하되 좁은 폭에서 다섯 번째를 숨기는 방향.
- 반응형 하한 375px 기준으로 확인한다(393 x 852 함께 확인). DEC-0145의 실측 기준선.
