## 제목

🚀 [기능개선][저작권] 저작권 정책 페이지 문구 작성

## 본문

## 🔍 현재 문제점

- `/copyright` 페이지(#221)는 뼈대(섹션 제목)만 있고 실제 문구가 없다.
- 포스터 이미지를 자체 서버에 저장하는 근거가 볼트 결정(DEC-0191)으로 정리됐다 — 이제 문구를 정확하게 쓸 수 있다.
- 권리자 요청을 받을 실제 연락처(모니터링되는 이메일 등)는 아직 확정되지 않았다.

## 💡 해결 방안 / 제안 기능

- DEC-0191 내용을 반영해 각 섹션(서비스가 다루는 정보 / 포스터 이미지 / 명칭 / 권리자 요청 / 면책) 문구를 작성한다.
- 포스터 이미지 절은 저장 사실을 인정하고, 권리자 요청 채널을 가장 앞세운다. 허락을 받았다는 표현이나 "저장하지 않는다"는 표현은 쓰지 않는다.
- 연락처는 아직 확정되지 않았으므로 자리만 만들어두고, 확정되면 채운다.
- 법률 지식이 있는 사람의 검토 전까지는 검색 노출을 계속 차단한다.

## 🔧 작업 내용

- [ ] 권리자 요청 연락처 확정 (별도 확인 필요 — 확정 전까지 자리만 표시)
- [ ] 법률 검토 완료 후 검색 노출(NO_INDEX 해제) 여부 재검토
