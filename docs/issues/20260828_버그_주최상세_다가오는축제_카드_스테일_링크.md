## 🗒️ 설명

- 주최 상세 화면의 "다가오는 축제" 카드(UpcomingFestivalCard)가 "자세히 보기 →"라고 표시하면서 실제로는 href="/"(홈)로 연결된다
- 코드 주석에 "축제 상세(#45)가 develop에 아직 없어 임시로 홈에 연결한다"고 남아 있는데, 축제 상세 화면은 이미 머지되어 `/festivals/{id}`로 접근 가능하다
- 아티스트 상세 화면의 "예정 공연" 카드에서 동일한 패턴의 스테일 링크가 있었고 이미 실제 축제 상세로 수정된 바 있다 — 같은 수정이 이 카드에는 아직 반영되지 않았다

## 🔄 재현 방법

1. 주최 상세 화면(`/hosts/{id}`)으로 이동한다
2. "다가오는 축제" 카드의 "자세히 보기" 링크를 클릭한다
3. 해당 축제 상세가 아니라 홈으로 이동하는 것을 확인한다

## 📸 참고 자료

## ✅ 예상 동작

- "자세히 보기" 링크가 해당 축제의 실제 상세 화면(`/festivals/{festivalId}`)으로 이동해야 한다
