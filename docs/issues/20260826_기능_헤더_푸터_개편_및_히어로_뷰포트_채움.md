## 📝 현재 문제점

- 헤더의 프로필·알림·북마크 아이콘, 푸터의 소셜 아이콘과 회사·고객센터 링크는 로그인·SNS·해당 화면이 없는 상태에서 빈 플레이스홀더로 계속 표시되고 있다.
- 393×852(아이폰 기준) 화면에서 헤더 네비가 한 줄에 빡빡하고, 푸터 소셜 아이콘이 어색하게 줄바꿈되며 12px 텍스트가 작게 읽힌다.
- 히어로가 "화면 높이 − 헤더 높이"에 최대 높이 상한까지 걸려 있어, 큰 화면에서는 첫 화면을 다 채우지 못하고 아래 섹션이 삐져나온다 — 해상도마다 모양이 달라진다.
- 헤더가 스크롤하면 사라져 페이지 중간에서 이동 수단이 없다.
- 분실물은 MVP 이후 범위인데 헤더·푸터에 링크가 노출돼 있다.

## 🛠️ 해결 방안 / 제안 기능

- 플레이스홀더(프로필·알림·북마크·소셜 아이콘·화면 없는 링크)와 분실물 링크를 헤더·푸터에서 제거한다.
- 헤더: 640px 미만에서는 햄버거 버튼 → 드롭다운 메뉴. 모든 페이지에서 상단에 고정된다. 홈 히어로 위에서는 투명(흰 글자)으로 떠 있다가 히어로를 벗어나면 흰 배경이 서서히 나타난다. 로고·메뉴 간격을 넓힌다.
- 히어로: 뷰포트 높이 전체를 채우고 헤더 아래까지 올라간다 — 해상도와 무관하게 첫 화면이 곧 히어로다 (church-frontend 히어로 방식 참고). D-day 위치는 시안 좌표(y140)를 그대로 쓴다.
- 푸터: 로고·copyright·링크를 한 줄로 가운데 정렬한 미니멀 구성으로 바꾸고 텍스트를 키운다.

## ⚙️ 작업 내용

- 헤더: 플레이스홀더 제거, 햄버거 드롭다운, 상단 고정 + 투명↔솔리드 전환, 간격 확대
- 푸터: 미니멀 한 줄 구성, 텍스트 크기 확대
- 히어로 면 공용 컴포넌트와 헤더 전환 상태 공유 구조 추가, 홈 히어로(캐러셀·빈 상태·에러 상태)에 적용
- 1440·393 뷰포트, 스크롤 전환, 라우트 이동 시 동작 확인
