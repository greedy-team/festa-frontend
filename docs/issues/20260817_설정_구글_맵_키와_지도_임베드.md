## 제목

🔧 [설정][지도] 구글 맵 키·결제 설정과 축제 상세 지도 임베드

## 본문

## 📝 작업 내용

- 구글 클라우드 프로젝트와 결제 계정을 준비한다
- 지도 렌더에 필요한 API를 켜고 키를 발급한다
- 키에 HTTP referrer 제한을 걸어 다른 도메인에서 쓰지 못하게 한다
- Vercel에 환경변수를 등록한다 (Production·Preview·Development)
- 축제 상세의 오시는 길 섹션에 남겨둔 폴백 박스를 지도로 교체하고 축제 위치에 마커를 찍는다

## 🎯 필요한 이유

오시는 길은 지도 하나와 외부 길찾기 링크로만 구성하기로 확정됐다. 약도 이미지·경로 설명·지하철·버스·주차 안내를 전부 걷어냈기 때문에 지도가 그 섹션의 유일한 시각 요소다. 렌더 API는 비용 기준으로 구글 맵을 골랐고 프론트엔드가 직접 붙인다.

키와 결제 계정은 저장소 안에서 만들 수 있는 것이 아니라, 축제 상세 화면 이슈에서 분리했다. 그 이슈는 지도가 들어갈 자리를 폴백 박스로 남겨두고 먼저 나간다.

## ⚠️ 영향 범위

- 배포 환경. 앱 환경변수는 Vercel에 등록해야 빌드에 들어간다. GitHub Secrets에 넣어도 앱에 들어가지 않는다
- 축제 상세 화면의 오시는 길 섹션 한 자리
- **비용이 발생한다.** 무료 크레딧 한도와 초과 시 과금 정책을 확인하고, 키 제한을 반드시 걸어야 한다. 제한 없는 키가 공개 저장소 빌드에 실려 나가면 남이 우리 계정으로 호출할 수 있다
- 길찾기는 좌표로 넘기기로 확정돼 있으므로 place id를 도입하지 않는다
