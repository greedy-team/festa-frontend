## 제목

♻️ [리팩토링][mock][검색] 연관 검색어를 빈 배열로 고정하고 추천 검색어 UI 제거

## 본문

## 🔍 현재 문제점

- 검색 응답의 `relatedKeywords`는 결과 0건일 때 추천 검색어 목록을 담도록 설계됐고, MSW 핸들러도 0건이면 예시 추천어 3개를 채운다
- 백엔드가 이번 검색 API 범위에 연관 검색어 생성 기능을 넣지 않기로 했다고 전달했다 — 실제 API는 `relatedKeywords`를 항상 빈 배열로 내린다
- 그래서 MSW 응답과 실제 계약이 갈리고, 검색 화면의 "추천 검색어" 렌더 블록은 실제 환경에서 절대 동작하지 않는 코드가 된다
- 이 UI는 "API가 이미 relatedKeywords를 제공한다"는, 지금은 철회된 전제로 만들어졌다 (통합 검색 결과 화면 조립 이슈)

## 💡 해결 방안 / 제안 기능

- MSW `/search`·`/search/autocomplete` 핸들러의 `relatedKeywords`를 조건 없이 빈 배열로 맞춘다
- `relatedKeywords` 필드 자체는 응답 계약에 남으므로 타입 선언은 유지한다
- 검색 결과 0건 화면에서 추천 검색어 칩을 그리던 블록을 제거하고 "검색 결과가 없습니다." 안내만 남긴다
- 외부 동작 변경 내용: 검색 결과 0건일 때 나오던 "추천 검색어" 칩이 사라진다. 데이터 소스가 없어져 실제 환경에서는 늘 빈 상태였을 영역이다
