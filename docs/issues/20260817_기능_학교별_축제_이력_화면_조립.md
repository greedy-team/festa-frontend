## 본문

## 📝 현재 문제점

- 학교(host)별 축제 아카이브를 모아 보는 화면이 없다. DESIGN.md 20 Festival History 시안(node `273:473`)의 연도 필터·정렬·페이지네이션도 미구현.
- 이 화면은 School Detail(DESIGN.md `10 School Detail`, node `68:798`)에서 "축제 이력 더보기" 같은 진입점으로 연결되는 걸 전제하는데, School Detail 자체가 아직 없다. 즉 이 이슈가 끝나도 당분간 앱 안에 이 화면으로 들어오는 진입점은 없다 — 직접 URL로만 접근 가능한 상태다.

## 🛠️ 해결 방안 / 제안 기능

- `/hosts/{hostId}/history` 라우트로 조립한다. 나중에 School Detail이 `/hosts/{hostId}`로 붙을 것을 감안한 경로다.
- 전용 페이지네이션 API가 따로 없다 — `GET /hosts/{id}`는 미리보기 2건만 주는 `festivalHistory` 필드뿐이라 이 화면(연도 필터·정렬·페이지네이션 있는 전체 목록)엔 안 맞는다. 대신 이미 hostId·year·sort·페이지네이션을 지원하는 기존 `GET /festivals`를 그대로 재사용한다 (`?hostId=&year=&sort=&page=`). 학교 이름·연도 목록(`availableYears`)만 `GET /hosts/{id}`에서 가져온다.
- 연도 필터 칩(전체 + `availableYears`)과 정렬(최신순/오래된순) 실제 동작. 이 화면엔 검색창이 없다 (시안에도 없음).
- "학교 상세로" 링크는 School Detail이 없어 임시로 홈(`/`)에 연결한다. 카드 클릭도 상세 화면(08 Festival Detail)이 없어 동일하게 임시로 홈(`/`)에 연결한다.
- #42/#49에서 만든 `Pagination`·`AdSlot`(banner)·`SortDropdown`·`Chip` 공용 컴포넌트를 그대로 재사용한다.

## ⚙️ 작업 내용

- `src/features/hosts`: `Host` 타입(id/name/shortName/availableYears), `getHost` API(`GET /hosts/{id}`)
- `src/features/festivals/api.ts`의 `getFestivals`에 `hostId`/`year` 파라미터 추가
- `src/lib/festivalDate.ts`에 `festivalSeason` 헬퍼 추가 (시작월 기준 봄/가을 표기)
- `FestivalHistoryCard` 컴포넌트 — festival-card와 같은 크기지만 학교명 대신 계절 표기(`2025년 봄`)
- `src/app/hosts/[hostId]/history/page.tsx` 조립: 브레드크럼·타이틀 → 연도 필터 칩 + 정렬 → 카드 그리드 → 페이지네이션 → 광고 배너
