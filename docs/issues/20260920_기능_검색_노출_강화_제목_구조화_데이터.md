## 제목

🚀 [기능요청][SEO] 검색 결과 제목에 학교명·연도를 넣고 구조화 데이터를 추가한다

## 본문

## 🔍 현재 문제점

- 구글에는 색인돼 있지만 사람들이 실제로 치는 검색어에 잘 걸리지 않습니다. 건국대 일감연 라인업으로 검색하면 1페이지에 나오지 않습니다.
- 축제 상세의 검색 결과 제목이 축제명뿐입니다. 오름 일정·라인업·입장 안내처럼 학교명과 연도가 없어, 학교 이름으로 찾는 검색과 매칭되지 않습니다. 대표 제목도 축제명만 담고 있습니다.
- 대학 축제 모음으로 검색하면 1페이지가 전부 연도와 총정리를 제목에 넣은 글입니다. 우리 사이트는 제목·설명·대표 제목 어디에도 모음이라는 말이 없고 연도도 없습니다. 축제 목록의 대표 제목은 축제 전체입니다.
- 구조화 데이터가 모든 페이지에 하나도 없습니다. 축제의 이름·날짜·장소·출연자를 이미 갖고 있는데 검색엔진에 행사로 알려 주지 않고 있습니다.
- 첫 방문 고지와 분석 동의 모달의 제목이 제목 태그로 들어가 있어, 모든 공개 페이지의 문서 구조에 서비스 내용과 무관한 제목 두 개가 끼어 있습니다.

## 💡 해결 방안 / 제안 기능

- 축제 상세의 검색 결과 제목에 학교명과 연도를 넣습니다. 제목은 데이터로 자동 생성되므로 기존 페이지와 앞으로 생길 페이지에 함께 적용됩니다.
- 축제 상세의 대표 제목은 화면 글자를 그대로 두고, 보조 기술과 검색엔진이 읽는 텍스트로 학교명과 연도를 덧붙입니다.
- 학교 페이지의 제목을 다듬습니다. 해마다 새로 생기는 축제 상세와 달리 학교 페이지는 주소가 바뀌지 않아 검색 신뢰가 쌓이는 자리입니다.
- 홈과 축제 목록의 제목·대표 제목에 연도와 대학 축제 모음을 넣습니다. 연도는 고정값으로 적지 않고 계산합니다.
- 축제 상세에 행사 구조화 데이터를, 축제 목록에 항목 목록 구조화 데이터를 추가합니다. 공개되지 않은 출연자는 넣지 않습니다.
- 고지·동의 모달의 제목을 제목 태그가 아닌 요소로 바꿉니다. 대화상자와의 이름 연결은 유지해 보조 기술 동작은 그대로 둡니다.
- 사이트맵의 수정 시각은 이번에 다루지 않습니다. 응답에 수정 시각이 없어 넣을 값이 없고, 임의의 날짜는 검색엔진에 거짓 정보를 주는 일입니다.
