## 제목

🚀 [기능요청][홈][히어로] 다가오는 축제 0건일 때 히어로 배경 이미지 지원 (형식만)

## 본문

## 🔍 현재 문제점

- 다가오는 축제가 0건인 시즌(방학 등)에는 홈 히어로가 파란 단색 화면 + 바로가기 3개만 보인다.
- 이 빈 상태 히어로는 배경색이 코드에 고정되어 있어서, 배경 이미지를 얹을 방법이 없다.
- 지금 당장 사진을 넣을 계획은 없지만, 나중에 브랜드 이미지 한 장을 배경으로 쓰고 싶을 때 받아줄 구조가 없어 매번 컴포넌트를 손대야 한다.

## 💡 해결 방안 / 제안 기능

- 빈 상태 히어로가 선택적으로 배경 이미지를 받을 수 있는 형식을 만든다. 백엔드 응답과 무관한 정적 이미지 방식이다.
- 배경 이미지가 지정되지 않으면 지금과 똑같이 파란 단색 화면이 그대로 뜬다. 기본 동작은 바뀌지 않는다.
- 배경 이미지가 지정되면 그 사진을 배경으로 깔고, 흰색 텍스트 가독성을 위해 스크림을 얹는다.
- 이미지 파일 자체는 이번 작업에서 추가하지 않는다. 받아줄 형식만 만든다.
