## 📝 현재 구조의 문제

- 함수·컴포넌트 위에 남기는 설명이 파일마다 일반 주석과 JSDoc 형식이 섞여 있어, 에디터가 자동으로 보여주는 툴팁 설명을 활용하지 못하는 곳이 많다.
- 설명이 있으면 이해하기 쉬운 함수인데 주석이 아예 없는 곳도 있다.

## 🛠️ 개선 방향

- 이미 있는 설명 주석을 JSDoc 형식으로 통일한다.
- 설명 없이는 동작이 바로 이해되지 않는 함수·컴포넌트에 한해 JSDoc 주석을 새로 작성한다.
- 이 저장소의 기존 주석 작성 원칙(꼭 필요한 경우에만 작성 — 모든 함수에 일괄로 달지 않음)은 그대로 유지하고, 형식만 JSDoc으로 맞춘다.
