## 본문

## 📝 작업 내용

`.claude/commands/`의 커맨드 7종을 Codex에서도 쓸 수 있게 한다.

- `/issue` `/issue-branch` `/commit` `/report` `/pr-description` `/rp` `/cr`
- 상위 `festa` 레포가 이미 쓰는 방식을 그대로 따른다: 도구 중립 진입점 문서 + 에이전트 스킬 + Codex 프롬프트

규칙 자체는 한 곳에만 두고 각 CLI가 그 한 곳을 가리키게 한다. 같은 내용을 두 벌로 관리하면 반드시 어긋난다.

## 🎯 필요한 이유

지금 이슈·브랜치·커밋·PR 규칙은 Claude Code 전용 경로에만 들어 있다. Codex로 작업하는 사람은 브랜치명 규칙도, 커밋 형식도, 빈 브랜치를 먼저 푸시해야 한다는 것도 알 수 없다.

규칙을 지키지 않으면 실제로 깨지는 것들:

- 브랜치명이 `타입_이슈번호_슬러그`가 아니면 PR 머지 시 이슈 자동 종료가 동작하지 않는다
- 커밋 메시지에 `#이슈번호`가 없으면 이슈 타임라인에 커밋이 잡히지 않는다
- 브랜치를 커밋과 함께 처음 올리면 같은 문제가 생긴다
- `develop`이 아닌 곳에서 분기하면 충돌이 난다

도구를 바꿨다는 이유로 규칙이 무너지면 안 된다.

## ⚠️ 영향 범위

`festa-frontend` 레포의 문서·설정 파일만. 빌드·배포·런타임에는 영향 없다.

`festa-backend`는 `.claude/commands/`가 아직 없어 이번 범위에서 제외한다.
