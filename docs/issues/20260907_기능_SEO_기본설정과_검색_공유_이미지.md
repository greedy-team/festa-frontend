🚀 [기능요청][SEO] 검색 노출 기본 설정과 FESTA 공유 이미지 적용

## 본문

## 🔍 현재 문제점

- 공개 페이지 대부분이 같은 제목과 설명을 사용해 축제·학교·아티스트별 내용을 검색 결과에서 구분하기 어렵다.
- 검색엔진에 전달할 공개 페이지 목록과 대표 주소, 검색에서 제외할 화면의 기준이 정리되어 있지 않다.
- favicon이 Vercel 기본 이미지이며, 링크를 공유했을 때 FESTA와 해당 축제를 보여주는 대표 이미지가 없다.
- SEO와 AEO가 모두 필요하지만, 이번 작업은 기존 공개 페이지의 SEO를 우선한다.

## 💡 해결 방안 / 제안 기능

- 각 페이지의 실제 내용에 맞는 검색 제목·설명·대표 주소를 제공한다.
- SEO 적용 대상은 홈·축제·학교·아티스트 등 공개 사용자 페이지로 한정한다. 관리자·쇼케이스에는 제목·설명·공유 이미지 작업을 하지 않고, 검색엔진에 제출할 목록에서 제외하고 검색 비노출 여부만 확인한다.
- FESTA의 F를 축제 깃발로 해석한 심벌을 준비하고, 기존 인디고 색과 타이포 중심 디자인을 유지한다.
- 사용자가 제공한 공통 공유 이미지를 압축한 `public/festa-og-image.jpg`를 연결한다. 축제별 공유 제목·설명에는 실제 축제명·날짜·공개 라인업을 사용한다.
- 로고·favicon·공유 이미지의 생성 프롬프트를 먼저 준비하고, 선택된 자산을 적용한다.
- AEO용 출처·확인일 데이터 확장과 신규 콘텐츠 대량 생성은 이번 범위에서 제외한다.
