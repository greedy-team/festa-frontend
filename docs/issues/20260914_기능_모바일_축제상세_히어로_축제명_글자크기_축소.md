## 제목

🚀 [기능개선][모바일][타이포그래피] 축제 상세 히어로 축제명 글자 크기를 모바일에서 줄인다

## 본문

## 🔍 현재 문제점

- `/festivals/{id}` 히어로의 축제명 제목이 `text-hero`(48px/700)로, 모바일 폭에서도 데스크톱과 같은 크기 그대로 나온다.
- 모바일에서 히어로 박스 크기 대비 제목이 과하게 커 보인다. #224에서 고친 축제 전체·아티스트 목록 제목과 같은 원인(`text-hero`에 반응형 분기가 없음)이다.

## 💡 해결 방안 / 제안 기능

- 축제 상세 히어로의 축제명만 모바일에서 한 단계 작은 크기로 낮춘다. 데스크톱은 지금 크기(48px)를 유지한다. #224와 같은 방식(기존 타이포 스케일 안에서 선택)을 따른다.
- 범위는 축제 상세 히어로 축제명으로 한정한다. 같은 `text-hero`를 쓰는 주최 상세·아티스트 상세 히어로, 홈 히어로는 이번 요청에 포함되지 않는다.
- 히어로의 다른 텍스트(날짜·장소·티켓 정보)는 이미 적절한 크기라 대상에서 뺀다.

## 🔧 작업 내용

- [ ] 축제 상세 히어로 축제명 모바일 크기 축소
- [ ] 데스크톱 크기 변화 없는지 확인
- [ ] 긴 축제명(2줄로 줄바꿈되는 경우)도 확인
- [ ] 375px 실측 확인 (DEC-0145 기준선)
