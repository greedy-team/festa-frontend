## 본문

## 🔍 현재 문제점

- #165에서 축제 상세 화면의 텍스트 최소 크기와 회색 단계 사용 기준을 정해 DESIGN.md 「상세 화면 공통 텍스트 규칙」으로 적었다. 읽어야 하는 텍스트는 14px 아래로 내려가지 않고, muted-soft(#9CA3AF, 흰 배경 대비 2.5:1)는 순번·placeholder·비활성·광고 라벨처럼 읽지 않아도 되는 자리에만 쓰며, 라벨·값 쌍은 라벨의 대비를 값 이상으로 둔다는 세 가지다.
- 주최 상세, 아티스트 상세, 통합 검색 결과 행은 축제 상세와 같은 타이포 스케일을 쓰고 있어 같은 문제를 갖고 있을 가능성이 크다. 검색 결과 행은 DESIGN.md 스펙 자체가 라벨 14/400 muted-soft로 적혀 있다.
- 축제 이력 카드, 예정 공연 카드, 자주 온 아티스트 카드, 출연 이력 섹션 등에서 muted-soft가 읽어야 하는 텍스트에 쓰이고 있는지 아직 목록화하지 않았다.

## 💡 해결 방안 / 제안 기능

- 세 화면에서 쓰는 텍스트 크기와 색 단계를 영역별로 목록화하고 실제 대비를 측정한다.
- DESIGN.md의 상세 화면 공통 텍스트 규칙을 그대로 적용한다. 새 토큰이나 새 규칙을 만들지 않는다.
- 검색 결과 행 스펙(result-row)의 라벨 색을 규칙에 맞게 고친다.
- 밝은 배경 위 텍스트만 대상이다. 히어로가 없는 화면들이라 스크림 조정은 없다.
