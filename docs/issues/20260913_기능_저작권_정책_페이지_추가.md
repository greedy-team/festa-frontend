## 본문

## 🔍 현재 문제점

- FESTA는 축제 포스터 이미지를 화면에 노출하지만, 이미지 저작권·초상권에 대한 안내나 권리자 요청(수정·삭제) 창구가 서비스 어디에도 없다.
- 푸터에도 관련 링크가 없다. 지금 푸터는 화면이 없는 항목을 뺀 상태라(DEC-0129) 저작권 페이지가 생기기 전까지는 추가할 자리가 없었다.
- 서비스가 실제로 이미지를 어떻게 다루는지(원본 서버에서 불러오는지, 자체 서버에 저장하는지)에 따라 페이지에 적을 문구가 달라진다. 이 부분은 DEC-0018(포스터 이미지는 저장하지 않고 URL만 기록·임베드로 표시한다)과 실제 운영 방식이 상충하는 것으로 보여 별도 확인이 필요하다 — 아래 작업 내용 참고.

## 💡 해결 방안 / 제안 기능

- `/copyright`(가칭) 페이지를 새로 만들고, 아래 내용을 담는다.
  - 서비스가 다루는 정보의 성격(사실 정보 중심, 저작권 보호 대상 아님)
  - 포스터 이미지 출처와 처리 방식 — 실제 정책 확정 후 문구 확정(아래 작업 내용 참고)
  - 아티스트 사진을 게시하지 않는다는 안내(DEC-0063)
  - 대학·축제 명칭·로고는 각 소유자 자산이라는 안내
  - 권리자가 수정·삭제를 요청할 수 있는 연락 경로 (가장 중요한 부분)
  - 정보 정확성에 대한 면책
- 광고 슬롯이 있는 서비스이므로 "비영리" 같은 표현은 넣지 않는다.
- 푸터에 링크를 추가한다. 라벨은 "저작권 정책" 등.
