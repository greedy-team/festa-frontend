## 제목

🔧 [설정][E2E] 사용자 화면 핵심 시나리오 E2E 테스트 도입

## 본문

## 🔍 현재 문제점

- 유닛테스트(#100)는 순수 함수 단위 검증만 하고, 실제 브라우저에서 페이지 이동·검색·폼 제출 같은 사용자 흐름은 검증하지 못한다
- "목표했던 타겟 환경에서의 서비스 핵심 기능 동작 확인" 요구사항에 E2E 테스트도 포함돼 있는데 아직 없다
- 홈→상세 이동, 검색·필터, 폼 제출 같은 흐름이 실제로 깨져도 유닛테스트로는 못 잡는다

## 💡 해결 방안 / 제안 기능

- Playwright를 도입해 로그인이 필요 없는 사용자 화면의 핵심 시나리오를 E2E로 커버한다
- 커버 시나리오: 홈→축제 상세 이동, 축제 목록 검색·필터, 아티스트 목록 검색, 아티스트 상세→예정 공연 이동, 통합 검색(`/search`), 주최 상세→축제 이력 전체보기

## 🔧 작업 내용

- [ ] Playwright 설치 및 최소 설정(`playwright.config.ts`)
- [ ] 홈 → 축제 상세 이동 시나리오 (카드 클릭 → 상세 페이지 축제명·D-day 노출)
- [ ] 축제 목록 검색·필터 시나리오 (검색어/필터 적용 → 결과 반영 → 상세 이동)
- [ ] 아티스트 목록 검색 시나리오 (검색어 입력 → 결과 필터링)
- [ ] 아티스트 상세 → 예정 공연 이동 시나리오 (카드 클릭 → 해당 축제 상세로 정확히 이동)
- [ ] 통합 검색(`/search`) 시나리오 (검색어 입력 → 결과 노출)
- [ ] 주최 상세 → 축제 이력 전체보기 시나리오 (상세 진입 → "전체 보기" → `/hosts/[id]/history` 이동, 목록 노출)
- [ ] CI에 E2E 실행 워크플로우 추가
