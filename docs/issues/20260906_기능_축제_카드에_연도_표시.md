# 🚀 [기능요청][축제목록][홈] 축제 카드 기간 위에 연도를 표시한다

## 🔍 현재 문제점

- 축제 전체 목록은 카드마다 기간을 05.07 ~ 05.09 형태로만 보여준다. 연도가 어디에도 없다.
- 이 목록은 여러 해의 축제가 한 화면에 섞여 나오는 유일한 화면이다. 최신순으로 정렬해도 올해 축제와 지난해 축제가 같은 모양으로 놓여 구분되지 않는다.
- 연도는 응답에 이미 들어 있다. 화면에서 앞자리를 잘라내고 있을 뿐이라 데이터를 더 받아올 필요가 없다.
- 홈의 최근 등록된 축제 카드가 목록 카드와 같은 모양을 쓴다. 목록만 고치면 두 화면의 카드가 갈린다.

## 💡 해결 방안 / 제안 기능

- 기간 바로 위에 연도를 별도 줄로 넣는다. 학교명 / 축제명 / 연도 / 기간 네 줄이 된다.
- 축제가 해를 걸치면 시작 연도만 적지 않고 두 연도를 함께 적는다. 아래 기간과 어긋나 보이지 않게 한다.
- 축제 전체 목록과 홈 최근 등록된 축제 카드 두 곳에 함께 적용한다.
- 연도와 기간은 같은 크기와 색을 쓰고 간격만 좁혀 한 덩어리로 읽히게 한다. 새 색이나 새 토큰을 만들지 않는다.
- 축제 상세 히어로, 검색 결과 행, 주최 상세 카드, 관리자 검수 표의 기간 표기는 건드리지 않는다. 그 화면들은 이미 맥락이 좁혀져 있어 연도가 필요하지 않다.
