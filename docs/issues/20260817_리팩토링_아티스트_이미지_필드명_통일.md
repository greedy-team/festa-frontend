## 본문

## 📝 현재 구조의 문제

- 아티스트 이미지를 가리키는 필드명이 mock 응답마다 다르다. artists.ts는 portraitUrl, hosts.ts의 frequentArtists는 photoUrl, search.ts는 avatarUrl을 쓴다. 전부 같은 값인데 응답마다 이름이 다르다.

## 🛠️ 개선 방향

- 세 필드명을 imageUrl 하나로 통일한다. 이 이름은 DEC-0081과 API 명세 수정 목록의 관련 항목이 이미 확정했다.
