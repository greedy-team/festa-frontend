## 제목

🚀 [기능요청][접근성] 아이콘 버튼 라벨·모션 감소 대응 적용

## 본문

## 📝 현재 문제점

- 아이콘만 있는 버튼(nav 벨·북마크, 히어로 화살표, 바텀시트 닫기, footer 소셜 아이콘, 페이지네이션 화살표 등)에 스크린리더용 라벨이 없어 어떤 동작인지 전달되지 않는다
- 스크롤·마운트 페이드인 애니메이션(PageFadeIn, FadeInSection)이 모션에 민감한 사용자를 위한 감소 옵션을 전혀 고려하지 않는다
- 이미지에 alt 텍스트가 누락된 자리가 있다

## 🛠️ 해결 방안 / 제안 기능

- 아이콘 전용 인터랙티브 요소에 aria-label 추가
- 순수 장식용 아이콘·구분선에는 aria-hidden 처리
- prefers-reduced-motion 미디어 쿼리로 애니메이션을 줄이거나 끄는 처리 추가
- 누락된 이미지 alt 텍스트 보강

## ⚙️ 작업 내용

- 코드베이스 전수 조사로 아이콘 전용 버튼·링크 목록화 후 aria-label 일괄 추가
- PageFadeIn·FadeInSection에 prefers-reduced-motion 대응 추가
- 이미지 alt 텍스트 점검 및 보강

포커스 상태(focus-visible) 디자인과 색 대비 감사는 이번 작업 범위에서 제외한다. 포커스 상태는 디자인 결정이 먼저 필요하고, 색 대비는 현재 색상 토큰을 바꿀 계획이 없어 별도로 다루지 않는다.
