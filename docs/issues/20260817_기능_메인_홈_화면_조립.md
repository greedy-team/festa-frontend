## 🛠️ 해결 방안 / 제안 기능

### 메인 홈 화면

- 06-D 시안 순서(히어로 → 최근 등록된 축제 → 최근 분실물 + 광고)대로 홈 화면을 조립한다
- 최근 분실물 패널, 광고 슬롯 컴포넌트를 새로 만든다
- 히어로 패널의 "자세히 보기" 링크를 추가한다. 다만 실제 목적지는 미정이다 — 축제 상세 화면 자체가 아직 없고, 히어로 카드 클릭 시 어떤 방식으로 반응할지도 확정되지 않았다 (DESIGN.md Known Gaps: 인라인 확장 / 커튼콜 / 상세 이동 세 안이 검토 중). 우선 임시로 홈(`/`)으로 연결해두고, 인터랙션 방식과 목적지 화면이 정해지면 후속 작업으로 교체한다

### 축제 목록 화면

- 17 시안대로 `/festivals` 목록 화면을 조립한다: 축제 카드 그리드(10개, 5-up × 2행), 페이지네이션, 정렬(최신순/다가오는 순) 실제 동작, 검색창은 기존 SearchPill 관례대로 표시 전용
- 카드 클릭은 상세 화면(DESIGN.md `08 Festival Detail`, node `65:530`)이 아직 없어 임시로 홈(`/`)에 연결한다. 목적지 화면이 정해지면 후속 작업으로 교체한다
- 광고 슬롯(`AdSlot`)을 `panel`(420px, 홈 정보 행) / `banner`(96px, 축제 목록 하단) variant를 가진 공용 컴포넌트로 일반화한다 (`src/components/ui/AdSlot.tsx`)
