## 제목

🔧 [설정][유닛테스트] adminErrorMessage 라벨 매핑 테스트 추가

## 본문

## 🔍 현재 문제점

- `adminError.ts`의 `adminErrorMessage`는 관리자 화면 에러 코드를 사용자 문구로 매핑하는 함수인데 유닛테스트가 없다
- 정의되지 않은 코드가 오면 코드를 괄호에 남기는 폴백 분기(운영자 제보 편의 목적)가 있는데 검증되지 않았다

## 💡 해결 방안 / 제안 기능

- `ADMIN_ERROR_CODE`에 정의된 코드별 문구 매핑과, 미정의 코드가 왔을 때 `처리 중 문제가 발생했습니다 (코드)` 형태로 떨어지는지를 검증하는 테스트를 추가한다
