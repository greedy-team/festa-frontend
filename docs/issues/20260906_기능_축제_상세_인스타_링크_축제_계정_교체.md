## 본문

## 🔍 현재 문제점

- 축제 상세 화면 히어로 우상단의 인스타그램 아이콘 링크가 주최(학교) 공식 계정을 가리킨다.
- GET /api/festivals/{id} 응답 최상위에 축제 계정 instagramUrl 필드가 새로 추가됐다 (nullable). 기존 host.instagramUrl(학교 공식 계정)은 응답에 그대로 유지된다.
- festival.instagram_url은 ERD 확정 컬럼인데 지금까지 서비스 응답으로 나가는 경로가 없었다.
- 축제 상세는 그 축제 하나를 보는 화면이므로 학교 공식 계정보다 축제 자체의 인스타 계정이 붙는 것이 자연스럽다.
- DESIGN.md 축제 상세 절이 인스타 링크를 "주최의 인스타그램"으로 서술하고 있어 화면과 함께 갱신이 필요하다.

## 💡 해결 방안 / 제안 기능

- 히어로 인스타 링크의 소스를 응답 최상위 instagramUrl(축제 계정)로 교체한다.
- 축제 계정이 없으면 인스타 아이콘 자체를 그리지 않는다. 주최 계정으로 대체(fallback)하지 않는다.
- 주최 공식 사이트(host.homepageUrl) 링크와 주최 pill은 지금 그대로 둔다.
- host.instagramUrl은 이 화면에서 더 이상 쓰지 않는다. 주최 상세 화면에도 인스타 노출 자리가 없어 학교 공식 계정은 서비스에서 미노출 상태가 된다.
- 인스타 링크의 접근성 라벨을 "축제 인스타그램"으로 바꾼다.
- 깨진 URL 노출을 막는 기존 safeHttpUrl 가드는 유지한다.
