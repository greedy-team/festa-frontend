## 제목

🔧 [설정][유닛테스트] genreLabel 라벨 매핑 테스트 추가

## 본문

## 🔍 현재 문제점

- `artistGenre.ts`의 `genreLabel`은 아티스트 장르 열거값을 한글 라벨로 매핑하는 함수인데 유닛테스트가 없다
- `admission.ts` 라벨 매핑과 같은 성격이라 같은 패턴(명세 밖 값 폴백 포함)으로 커버할 수 있다

## 💡 해결 방안 / 제안 기능

- 4개 장르(HIPHOP/BALLAD_RNB/BAND/DANCE) 매핑과, `genre`가 `null`이거나 명세 밖 값일 때 "장르 미상"으로 떨어지는지를 검증하는 테스트를 추가한다
