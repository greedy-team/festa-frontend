## 제목

🔧 [설정][라인업] LineupArtist에서 order 필드 제거

## 본문

## 🔍 현재 문제점

- `LineupArtist` 타입(`features/festivals/types.ts`)과 목데이터가 아티스트마다 `order` 필드를 갖고 있고, `LineupSheet.tsx`(전체 라인업 바텀시트)가 이 값을 화면 순번으로 그대로 찍는다
- 백엔드 결정(DEC-0109)은 이 필드를 응답에 두지 않기로 정했다 — 배열 순서 자체가 계약이 되고, 순번 표기는 프론트가 인덱스로 만든다
- 이유는 임포트 데이터에 결번이 생길 수 있는데(연속성 검증 없음), 서버 값을 그대로 찍으면 그 결번이 화면에 그대로 샌다는 것이다

## 💡 해결 방안 / 제안 기능

- `LineupArtist`에서 `order: number` 제거
- `LineupSheet.tsx`의 순번 표기를 서버 값 대신 배열 인덱스(`i + 1`)로 바꾼다
- 목데이터·목 핸들러에서도 `order` 필드를 제거해 실제 계약과 맞춘다
- 아티스트 나열 순서·개수 등 다른 동작에는 영향이 없다 — 화면은 이미 배열 순서를 그대로 따르고 있고 `order` 값으로 정렬하지 않는다
