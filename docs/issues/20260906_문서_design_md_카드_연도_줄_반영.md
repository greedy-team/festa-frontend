# 📄 [문서][디자인시스템] DESIGN.md 카드 스펙에 연도 줄을 반영한다

## 🔍 현재 문제점

- #182에서 축제 전체 목록 카드와 홈 최근 등록 카드에 연도 줄이 들어가 네 줄 구성이 됐는데, DESIGN.md의 두 컴포넌트 스펙은 아직 학교명 / 축제명 / 기간 세 줄로 적혀 있다.
- 홈 06-D 구조 절의 최근 등록된 축제 항목도 세 줄만 나열한다. 이 문서를 보고 화면을 만들면 연도가 빠진다.
- 연도를 목록 카드에만 두고 히어로와 상세에는 두지 않기로 한 판단이 문서 어디에도 없다. 근거가 없으면 다음 사람이 히어로에도 연도를 넣거나, 반대로 목록의 연도를 군더더기로 보고 지운다.
- 카드에 줄이 하나 늘어 실제 렌더 높이가 커졌지만 피그마는 그대로다. 문서의 치수는 피그마 실측값이라 코드에서 잰 값으로 덮으면 안 된다.

## 💡 해결 방안 / 제안 기능

- 두 카드 컴포넌트의 산문 스펙과 홈 구조 절의 구성 나열에 연도 줄을 추가한다.
- 연도를 목록 카드에만 두는 판단과 그 근거를 문서에 남기고, 히어로와 상세가 연도를 쓰지 않는 이유를 함께 적는다.
- 카드 높이와 y좌표는 손대지 않는다. 피그마 실측값이 원본이고 아직 피그마에 반영되지 않았다. 대신 반영 대기 항목으로 남겨 다음 피그마 정리 때 함께 처리하게 한다.
- 문서만 고친다. 화면 코드는 이미 #182에서 끝났고 이 작업은 동작을 바꾸지 않는다.
