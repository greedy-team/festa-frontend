## 본문

## 📝 현재 문제점

축제 상세의 라인업과 주최 상세의 「자주 온 아티스트」에서 아티스트를 눌러 갈 곳이 없다. "이 아티스트가 어느 축제에 왔었나"는 과거 라인업 아카이브의 핵심 조회 방향인데 화면이 없다.

`GET /artists/{id}`는 MSW 목이 이미 응답한다. 이름·다른 이름·장르·인스타그램, 예정 공연 5건과 전체 건수, 출연 이력 5건과 전체 건수가 들어 있다.

다만 이 화면은 히어로를 그릴 방법이 정해지지 않은 상태로 막혀 있었다. 초상권 때문에 아티스트 사진을 쓰지 않기로 확정됐는데, 대체 이미지 안("이니셜 + 이름 해시 색상")은 미확정으로 남아 있었다.

## 🛠️ 해결 방안 / 제안 기능

`/artists/[id]` 경로를 만들고 `GET /artists/{id}` 응답으로 세 영역을 그린다 — 히어로, 예정 공연, 출연 이력. 사진이 없으므로 텍스트 중심 화면이 된다.

대체 이미지는 이 이슈에서 확정한다. 아래 설계 결정 참고.

같은 이슈에서 이 화면의 구성 요소와 배치 원칙을 DESIGN.md에 추가한다. 1440 좌표 레이아웃은 옮기지 않는다 — 시안의 픽셀은 비율과 위계의 근거이지 계약이 아니고, 세부는 피그마를 직접 본다.

## ⚙️ 작업 내용

1. 라우트 — `/artists/[id]`. 아티스트 단건 조회 함수를 추가한다

2. 대체 이미지 — 이름의 이니셜과 이름을 해시한 색상으로 아바타를 만든다. 축제 라인업·주최 상세에서도 같은 것을 쓸 수 있게 공용 컴포넌트로 둔다

3. 히어로 — 대체 이미지, 이름, 다른 이름, 장르, 인스타그램 링크

4. 예정 공연 — `upcomingShows`를 그린다. 각 항목은 축제 상세로 링크한다. 응답이 주는 5건과 전체 건수를 함께 표기한다

5. 출연 이력 — `past-lineup-row`(1280×56)를 만들고 `appearances`를 그린다. 5건과 전체 건수를 함께 표기한다

6. 없는 아티스트 — 404를 받으면 Next.js의 not-found로 넘긴다

7. DESIGN.md에 이 화면의 구성 요소와 배치 원칙을 범용 규칙으로 추가한다. 좌표 레이아웃은 옮기지 않는다. 새로 만든 공용 컴포넌트는 `/showcase`에 등재한다

## 📌 확정한 설계 결정

- **대체 이미지를 이니셜 + 이름 해시 색상으로 확정한다.** 사진을 쓰지 않기로 한 결정에 딸린 안으로 제시됐다가 미확정으로 남아 있던 것이다. 포스터 틴트가 이미 같은 원리(식별자를 해시해 팔레트에서 색을 고름)로 동작하므로 그 방식을 재사용한다. 사람마다 색이 갈려서 목록에서 구분이 되고, 매번 같은 색이 나온다
- **응답의 `imageUrl`을 읽지 않는다.** 필드는 남아 있지만 사진을 쓰지 않기로 했으므로 값이 항상 비어 있다. 지금 이 필드를 읽는 코드를 만들면 영원히 비어 있는 분기를 유지하게 된다. 필드 존치 자체는 API 계약 쪽에서 결정될 문제다
- **장르가 비어 있으면 칩을 그리지 않는다.** 실측 133명 중 36명이 빈 값이라 예외가 아니라 다수 케이스다. "미분류" 같은 문구를 새로 만들지 않는다
- **예정 공연의 D-day는 축제 시작일이 아니라 그 아티스트의 공연일 기준이다.** 명세가 이 엔드포인트만 그렇게 정해두었다. 3일짜리 축제의 마지막 날 공연이면 축제 D-day와 값이 다르게 나오는 것이 정상이다
- **id는 이 응답의 `id`를 쓴다.** 아티스트 목록과 주최 상세는 같은 대상을 `artistId`로 준다. 이슈 #40의 결론이 나면 맞춘다
- **없는 아티스트 판별은 HTTP status로만 한다.** 코드별 사용자 문구 정책이 아직 없다

## 🚫 범위에서 빼는 것

- 아티스트 목록 화면. 별도 이슈다
- 출연 이력 전체 조회와 페이지네이션. 응답이 5건과 전체 건수만 주고, 전체 목록은 축제 목록 화면(`artistId` 필터)의 몫이다. 축제 목록 화면이 없는 동안 「더 보기」는 링크가 아닌 요소로 둔다
- 좋아하는 아티스트, 출연 소식 알림. MVP에 로그인이 없어 성립하지 않는다
- 아티스트 사진. 초상권 때문에 쓰지 않기로 확정됐다
- 광고 슬롯. 홈 외 화면의 광고 정책이 없다

## ⚠️ 알아 둘 것

이 화면은 사진이 없고 장르가 자주 비어 있어서, 남는 정보가 이름과 출연 기록뿐이다. **화면을 만들어 본 뒤 이 화면이 실제로 볼 만한지 판단해 보고서에 남긴다.** "사진을 빼고 텍스트만 남기면 이 화면이 핵심인지 자체가 열린다"가 화면 확정 당시의 열린 질문으로 남아 있고, 실물이 그 판단의 근거가 된다.
