## 본문

## 🔍 현재 문제점

- 주최(host)의 `type` 필드(`'UNIVERSITY' | 'LOCAL_GOV' | 'AGENCY' | 'ORGANIZATION'`)는 주최 상세 화면(#46) 작업에서 "확정된 ERD에 없는 필드"로 결론이 나서 화면 어디서도 참조하지 않는다
- 그 결론이 mock 응답·프론트 타입 선언에는 반영되지 않은 채 남아 있다 — 동작에 영향은 없지만, 결론 난 항목이 코드에는 "미확정"인 것처럼 남아 있다
- PR #65 작업 중 실제로 지워보며 범위를 확인했는데, 처음 추정(`hosts.ts` 한 줄)보다 훨씬 넓었다

## 💡 해결 방안 / 제안 기능

- `host.type`(및 `search.ts` 응답의 `hostType` — 같은 필드를 다른 이름으로 한 번 더 내려주고 있음)을 mock 응답·타입 선언에서 실제로 제거한다
- 실제 API도 이 필드를 내려주지 않는 것으로 맞춘다
