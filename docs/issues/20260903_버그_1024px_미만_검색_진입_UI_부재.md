## 제목

❗ [버그][검색][반응형] 1024px 미만에서 /search로 갈 수 있는 UI가 없다

## 본문

## 🔍 현재 문제점

- 헤더의 검색 폼이 lg(1024px) 미만에서 렌더되지 않는데, 그 자리를 대신할 진입 요소가 없다. 결과적으로 태블릿·모바일 폭에서는 통합 검색 화면에 도달할 방법이 사라진다.
- 모바일 햄버거 드롭다운은 홈·축제·아티스트 링크만 나열하고 검색 진입을 포함하지 않는다. 푸터에도 검색 링크가 없다.
- 반응형은 정식 지원 범위에 들어와 있는데(DEC-0145) 검색만 데스크톱 전용 기능처럼 남아 있다.
- 실제 동작: 1024px 미만에서 검색 화면으로 갈 수 있는 UI가 없다. 주소창에 /search를 직접 입력해야만 도달한다.
- 예상 동작: 지원하는 모든 폭에서 검색 화면으로 갈 수 있는 요소가 하나는 보여야 한다.

## 🔄 재현 방법

1. 브라우저 창 폭을 1024px 미만(예: 390px)으로 줄인다
2. 홈이나 축제 목록 등 아무 사용자 화면을 연다
3. 헤더에서 검색 입력이 사라진 것을 확인한다
4. 햄버거 메뉴를 열어도 검색 항목이 없는 것을 확인한다
5. 푸터까지 내려도 검색 링크가 없는 것을 확인한다

## 💡 해결 방안

- 좁은 화면에서 검색 폼을 아이콘 버튼으로 축소하고, 누르면 입력이 펼쳐지거나 검색 화면으로 이동하게 한다
- 또는 햄버거 드롭다운 안에 검색 항목을 넣는다
- 어느 쪽이든 터치 타깃 44px 확보가 필요하다

## 📸 참고 자료

- `src/components/layout/Header.tsx` — 검색 폼 래퍼가 `hidden lg:block`이라 1024px 미만에서 렌더되지 않는다. 같은 자리 주석은 "좁은 화면에서는 접어 자리를 아낀다"고 적고 있으나 펼칠 수단은 만들어지지 않았다
- `src/components/layout/Header.tsx` — 햄버거 드롭다운은 `NavLinks`(홈·축제·아티스트)만 렌더한다
- `src/components/layout/Footer.tsx` — 검색 링크 없음
- DESIGN.md 「Responsive Behavior > 미정의 영역」에 nav 햄버거 전환이 미정의로 남아 있다. 모바일 nav 설계가 필요한 자리다
