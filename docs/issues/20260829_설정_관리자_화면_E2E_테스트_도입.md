## 제목

🔧 [설정][E2E] 관리자 화면 E2E 테스트 도입

## 본문

## 🔍 현재 문제점

- 관리자 콘솔(로그인, 비로그인 접근 차단, 축제 심사)은 실제 서비스 운영에 직결되는 기능인데 E2E 검증이 없다
- `AdminGuard`의 리다이렉트 로직이나 로그인 실패 처리가 깨져도 잡을 방법이 없다
- 사용자 화면 E2E(#115)에서 도입하는 Playwright 인프라를 그대로 재사용한다 — 그 이슈가 먼저 진행돼야 한다

## 💡 해결 방안 / 제안 기능

- 관리자 로그인·가드·축제 심사 흐름을 E2E로 커버한다
- 커버 시나리오: 관리자 로그인(성공/실패), 비로그인 콘솔 접근 차단, 관리자 축제 심사(발행/반려)

## 🔧 작업 내용

- [ ] 관리자 로그인 성공/실패 시나리오 (잘못된 자격증명 → 에러 문구 / 정상 로그인 → 콘솔 진입)
- [ ] 비로그인 상태로 콘솔 접근 시 로그인 리다이렉트 시나리오 (`/admin/festivals` 직접 접근)
- [ ] 축제 심사(발행/반려) 액션 시나리오 (콘솔에서 액션 수행 → 상태 반영 확인)
- [ ] 테스트 계정 처리 방식 결정 (CI 시크릿으로 관리, 코드에 평문 금지)
