### 📌 작업 개요

주최(host) 기획 초기에 "다른 주체 유형도 추가하려던" 목적으로 넣었던 `type` 필드(예: `'UNIVERSITY'`)가 확정 ERD(#46)에서 빠졌는데도 목데이터·타입 선언에 8개 파일에 걸쳐 남아 있던 것을 실제로 제거했다(#125). #64 문서 작업 중 발견해 범위를 분리한 후속 이슈다.

### 🎯 구현 목표

- 실제 화면 코드(`src/app`, `src/features`)에서 `host.type`을 참조하는 곳이 없음을 재확인
- 타입 선언·목데이터·핸들러 응답에서 필드를 전부 제거
- `tsc --noEmit`으로 누락 없이 다 지웠는지 검증

### ✅ 구현 내용

- **확인**: `host.type`을 실제로 렌더링·분기에 쓰는 화면 코드는 없음을 재확인 — 전부 타입 선언과 목데이터에만 존재

  - `src/mocks/handlers/hosts.ts`, `festivals.ts`, `search.ts` — 응답 객체에서 `type`/`hostType` 필드 삭제
