### 📌 작업 개요

관리자 콘솔이 「보는 화면」(축제 검수·발행)까지만 있고 값을 넣거나 고치는 화면이 없었다.
아티스트·주최는 백엔드 API가 8월에 들어왔는데 3주째 쓰는 화면이 없었고, 축제·라인업은
백엔드 `#106`·`#112`가 9월 1일 착지하며 선행 조건이 사라졌다. 이 브랜치는 그 위에
**임포트 → 검수 → 교정 → 발행** 루프 전체를 화면으로 닫는다 — 크롤링 임포트, 아티스트,
주최, 축제 폼, 라인업 편집.

착지 도중 실데이터(크롤러 산출물 381행)로 임포트까지 돌려 화면·계약 오류 3건을 실측으로
잡아 함께 고쳤다.

**보고서 파일**: `docs/reports/20260902_122_관리자_데이터_교정_화면_추가.md`

### 🧭 결정 기록 (ADR)

#### enum 필드의 「선택 안 함」은 `null`로 보낸다

- **문제**: 관리자 수정 계약은 「빈 값은 빈 문자열」인데, `<select>`가 내는 `""`를 enum
  필드에 보내면 400(`InvalidFormatException`)이었다. 아티스트 등록의 기본 상태가 그거라
  화면이 막혀 있었다
- **선택**: 요청 직렬화 한 곳(`_shared/enumField.ts`)에서 enum의 `""`를 `null`로 바꾼다.
  String은 `""` 그대로, 숫자·시각은 `null`
- **대안**: 백엔드에 enum coercion 설정 추가 — 백엔드 변경을 늘리지 않기로 했다
- **트레이드오프**: 비우기의 의미가 도메인마다 갈린다. `Festival.update`는 무조건 대입이라
  `null`이 곧 비우기지만, `Artist.update`는 `if (genre != null)` 가드가 있어 `null`이
  「변경 없음」이다 — 아티스트 장르는 API로 비울 수 없고 폼이 문구로 알린다
- ⭐ **볼트 승격 권장** — DEC-0150이 전제한 enum coercion 설정이 백엔드에 없다. 실측표
  (String `""` 보존 · 날짜/숫자 `null` 강제 · enum 400)로 결정 노트의 정정이 필요하다

#### 상세 라우트 대신 네이티브 `<dialog>`

- **문제**: 등록·수정 화면을 `[artistId]` 같은 동적 라우트로 만들지, 목록 위 다이얼로그로
  만들지
- **선택**: 네이티브 `<dialog>` + `showModal()`. `LineupSheet`가 이미 쓰는 패턴
- **대안**: 동적 세그먼트 라우트 — `not-found`/`error` 경계가 딸려 오고, 병렬 브랜치와
  세그먼트 이름 충돌 위험이 붙는다
- **트레이드오프**: 폼 URL이 없어 직접 링크·새로고침 복원이 안 된다. 운영자 동선(표 →
  바로 고치기)이 더 짧아 감수했다

#### 폼 값은 이펙트 없이 「손대지 않았으면 서버 값」으로 파생한다

- **문제**: 단건 조회가 창이 열린 뒤 도착한다. 이펙트로 폼에 밀어넣으면 렌더 → setState
  → 렌더가 되고(`react-hooks/set-state-in-effect`), 늦은 응답이 입력을 덮어쓴다
- **선택**: `draft ?? toValues(server)`. 사용자가 한 글자라도 치면 draft가 서고 그때부터
  폼이 이긴다
- **대안**: `key`로 리마운트 — 다이얼로그가 닫혔다 열리며 깜빡인다
- **트레이드오프**: 없음. 세 폼(아티스트·주최·축제)에 같은 패턴

#### 미리보기 INVALID 행의 교정 동선을 사례로 가른다

- **문제**: 「검수에서 찾기」가 항상 빈 결과였다. 커밋 전엔 DB에 없고 INVALID 행은 커밋해도
  안 들어가며, 검수 화면의 `q`는 축제 이름만 검색해(`LOWER(f.name) LIKE`) `import_key`로는
  커밋 후에도 0건이다
- **선택**: 라인업 행만 INVALID면 같은 미리보기의 축제 섹션에서 이름을 찾아 이름 검색
  링크로, 축제 행 자체가 INVALID면 등록 화면으로. 표 위에 두 갈래를 안내한다
- **대안**: 백엔드 `q`가 `import_key`도 검색하게 요청 — 프론트에서 이름을 이을 수 있어
  불필요했다
- **트레이드오프**: 링크는 새 탭으로 연다. 미리보기가 컴포넌트 상태뿐이라(재조회 API
  없음) 같은 탭으로 가면 돌아올 수 없다

#### 검수 표를 `table-fixed`로 고정하고 열 크기 조절을 붙인다

- **문제**: 실데이터의 긴 URL이 auto 레이아웃 표를 부풀렸다
- **선택**: `md:table-fixed`, 긴 값은 말줄임 + `title`, 열 경계 드래그(순수 React,
  포인터 캡처, 최소 64px, 저장 안 함). 폭은 CSS 변수 + `md:w-[var(--col-w)]`로 md에서만
  적용해 모바일(auto 레이아웃, 접힌 열)에 새지 않게 했다
- **대안**: `min-w` 복원 + 가로 스크롤 — 한 화면에 안 들어온다
- **트레이드오프**: 새로고침하면 기본 폭. 필요해지면 localStorage 한 줄

#### 관리자 화면을 모바일 반응형 범위에 넣는다

- **문제**: 볼트 DEC-0145는 관리자 콘솔을 반응형 대상에서 제외했다
- **선택**: 사용자 결정으로 뒤집었다. 마크업 두 벌(카드+표) 없이 열 접기 + 서브라인
- **트레이드오프**: 375px 시각 실측은 미완 — 관리자 화면이 로그인·실 API 뒤라 목 없이
  스크린샷이 안 된다
- ⭐ **볼트 승격 권장** — DEC-0145의 관리자 제외 조항 정정

#### `feat_67`을 이 브랜치에 스쿼시로 흡수한다

- **문제**: 「이슈 하나 = 브랜치 하나」 규칙상 `#67`은 별도 PR이 정석이다

### 🔧 주요 변경사항 상세

#### 요청 직렬화 규칙 (`festivalForm.ts` · `enumField.ts` · `lineup/api.ts`)

HTML 입력이 내는 값은 전부 문자열이다. 요청으로 바뀔 때 타입별로 한 곳에서 처리한다 —
String은 `""` 그대로(서버가 공백을 삭제로 읽는다), 숫자·시각은 `""`를 `null`로 바꾸고
값은 `Number`로 확정(문자열 `"37.5"`를 서버 coercion에 맡기지 않는다), enum은
`enumOrNull`. `ticketOpenAt`은 브라우저 로컬 시간대로 왕복하며 초까지 보존한다 —
분에서 끊으면 손 안 댄 폼 저장이 서버 값의 초를 지운다.

**특이사항**:
- `coordinateError`가 좌표 쌍을 판정한다. 발행 축제는 둘 다 비우는 것도 막고(서버 409를
  선제 차단), 발행 여부와 무관하게 한쪽만 채운 것을 막는다

#### `adminFetch` 204 가드

DELETE 계열 전부가 지나는 자리라 호출부가 아니라 공용 계층에서 막았다. FormData
업로드는 헤더를 넘기지 않아 브라우저가 boundary 붙은 `Content-Type`을 만든다.

#### `FestivalReviewTable` 열 폭

`COLUMNS` 정의 + `DEFAULT_WIDTHS`(축제 열은 미지정 → 남는 폭 전부). 핸들의 `pointerdown`에서
`th.offsetWidth`를 실측해 시작 폭으로 쓰므로 auto 열도 잡힌다. 모바일에선 핸들을 숨긴다.
