### 🧭 결정 기록 (ADR)

#### `LineupArtist` 타입을 판별 유니온으로 변경
- **문제**: `id: number | null`과 `revealed: boolean`이 서로 무관하게 선언돼 있어 미공개 아티스트를 다룰 때 non-null assertion(`!`)이 필요했다
- **선택**: `revealed`로 `id`/`name`/`imageUrl`/`genre`의 유무가 갈리는 판별 유니온으로 재정의
- **트레이드오프**: 타입이 조금 더 복잡해지지만 `!` 없이 TypeScript가 자동으로 좁혀준다

#### 라인업 바텀시트를 네이티브 `<dialog>`로 구현
- **문제**: 커스텀 모달(div + onClick 백드롭)에 `role="dialog"`도, Esc 핸들러도, 포커스 트랩/복귀도 없었다
- **선택**: 네이티브 `<dialog>` + `showModal()`로 전면 교체 — 실제 컨텐츠는 `fixed` 자식으로 바텀시트 위치를 잡고, `<dialog>` 자체는 투명하게 둬서 백드롭 클릭 판정(`e.target === e.currentTarget`)만 담당하게 함
- **대안**: ARIA 속성만 패치 — Esc·포커스 트랩·포커스 복귀를 전부 손으로 구현해야 해서 브라우저에 위임하는 쪽을 택함
- ⭐ **볼트 승격 권장** — SortDropdown(이슈 #49)에 이어 "브라우저 네이티브 기능에 위임한다"는 같은 원칙의 두 번째 사례
