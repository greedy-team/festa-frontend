### 📌 작업 개요

축제 상세(`/festivals/[id]`)의 텍스트가 작고 흐려 읽기 어려운 문제를 고쳤다. 읽어야 하는 텍스트가 12~14px `muted-soft`(흰 배경 대비 2.5:1)로 깔려 있었고, 히어로는 ink 35% 스크림 한 단계라 밝은 포스터에서 흰 글자가 묻혔다. 같은 작업에서 라인업 바텀시트를 없앴다(#168 — #165에서 함께 처리). 실데이터 규모에서 시트가 할 일이 없었고, 이슈가 지적한 시트 안 텍스트는 고칠 대상이 아니라 시트와 함께 사라질 대상이었다.

### 🔍 문제 분석

**대비 실측 (WCAG AA — 본문 4.5:1, 큰 텍스트 3:1)**

| 조합 | 대비 |
|---|---|
| `muted-soft` #9CA3AF / 흰 배경 | 2.54 ✗ |
| `muted` #6B7280 / 흰 배경 | 4.83 ✓ |
| 흰 100% / ink 35% 위 밝은 포스터(#F2F0F7) | 2.48 ✗ |
| 흰 85% / 같은 조건 | 2.20 ✗ |
| 흰 100% / 검정 55% 위 같은 포스터 | 5.22 ✓ |
| 흰 100% / 검정 55% 위 순백 포스터 | 4.74 ✓ |

8번 세종연회의 실제 포스터가 밝은 라벤더 PNG라 이슈가 예로 든 화면이 그대로 재현됐다.

**이슈 본문과 현재 코드의 차이.** 이슈가 적은 "라인업 카드 아티스트 이름 13px", "바텀시트 아티스트 이름 14px"은 #159(2788054, 6a6b96f)에서 이미 17/700, 16/500으로 올라가 있었다. 남은 것은 날짜·순번·장르·입장 안내 라벨·오시는 길·히어로였다.

**바텀시트의 근거.** 현재 API에 있는 축제는 3일 × 4~5팀, 총 13팀이고 목 데이터도 하루 최대 4팀이다. 카드는 3명에서 끊고 나머지를 시트로 보냈으니 시트가 추가로 보여주는 것은 하루 1~2팀과 장르뿐이다. 순번은 배열 순서가 곧 순번이라(DEC-0109) 카드의 나열 순서와 같은 정보다. 시트 구조를 지키는 결정 기록은 없고 근거는 피그마 08-3 시안 하나였다.

### ✅ 구현 내용

#### 히어로 — 스크림을 홈과 같은 검정 55%로, 메타 3줄을 16px 흰 100%로

- **파일**: `src/features/festivals/components/FestivalHero.tsx`
- **변경 내용**: `bg-scrim-35` → `bg-scrim-hero`. 날짜·장소·티켓 3줄을 `text-caption-strong text-on-media/85` → `text-body text-on-media`, 아이콘 14 → 16.
- **이유**: 새 토큰 없이 기존 `scrim-hero`(홈 히어로가 쓰는 값)를 재사용한다. 단색 유지 — DESIGN.md의 "그라데이션 아님" 관례를 지킨다. 85% 불투명도는 밝은 포스터에서 대비를 잃어 100%로 올렸다.

#### 라인업 — 바텀시트 삭제, day 카드가 전원 + 장르

- **파일**: `src/features/festivals/components/LineupSheet.tsx` (삭제), `LineupSection.tsx`, `DayCard.tsx`
- **변경 내용**: `LineupSheet`와 그것을 여는 "전체 라인업 보기"·"+ 더보기"를 없앴다. `DayCard`가 그 날의 아티스트를 전부 나열하고 장르를 이름 옆 `text-caption text-muted`로 붙인다(없으면 안 그린다). 날짜는 `text-meta text-muted-soft` → `text-caption text-muted`. `LineupSection`은 상태가 사라져 `"use client"`를 떼고 서버 컴포넌트로 돌아왔다.
- **이유**: 위 문제 분석. 시크릿 게스트("공개 예정") 처리와 아바타 없음 규칙은 그대로다.

#### 라인업 — 공개된 아티스트 행이 아티스트 상세로 링크

- **파일**: `src/features/festivals/components/DayCard.tsx`
- **변경 내용**: `id`가 있는 아티스트 행을 `Link`(`/artists/{id}`)로 감쌌다. 행 전체가 타깃이고 우측에 `ChevronRight` 16 `muted-soft`, hover `bg-surface-field`. 카드 패딩 안쪽에서 `-mx-3 px-3 py-2`로 hover 배경만 텍스트보다 넓게 깐다. "공개 예정"은 링크가 아니라 chevron도 hover도 없다.
- **이유**: 아티스트 상세는 이미 있고 주최 상세의 자주 온 아티스트·검색 결과 행이 같은 곳으로 링크하는데 라인업만 안 눌렸다. 행 + chevron은 아티스트 목록 행(`ArtistRow`)이 쓰는 문법이라 새 스타일이 없다. hover가 없는 모바일에서는 chevron이 유일한 어포던스이고, 터치 타깃이 글자 21px에서 행 폭 × 37px가 된다.

#### 입장 안내 — 라벨 대비를 먼저 올리고 값을 한 단계 키움

- **파일**: `src/features/festivals/components/AdmissionInfo.tsx`
- **변경 내용**: 라벨 `text-muted-soft` → `text-muted`, 값 `text-caption-strong` → `text-body`.
- **이유**: 라벨이 값보다 흐리면 표로 읽히지 않는다. 라벨은 값과 같은 대비 단계 이상, 크기는 값이 한 단계 위.

#### 오시는 길 — 장소명 16px

- **파일**: `src/features/festivals/components/LocationSection.tsx`
- **변경 내용**: 장소명 `text-caption-strong` → `text-body`. 주소는 `caption muted`(4.8:1)라 그대로.

#### DESIGN.md — 상세 화면 공통 텍스트 규칙과 Festival Detail 절 갱신

- **파일**: `.claude/rules/DESIGN.md`
- **변경 내용**: Festival Detail 절 아래 「상세 화면 공통 텍스트 규칙」 3줄을 추가했다 — ① 읽는 텍스트는 `caption`(14) 아래로 내려가지 않는다, ② `muted-soft`는 읽지 않아도 되는 자리(순번·placeholder·비활성·광고 라벨)에만, ③ 라벨·값 쌍은 라벨 대비를 값 이상으로. 히어로 스크림 문장을 `scrim-hero`로, 라인업 절을 한 층 구조로, 입장 안내·오시는 길에 크기·색 토큰을, `day-card` 산문과 YAML(`typography: caption`, `size: 410×auto`)을 갱신했다. Scrim 절에 "축제 상세 히어로도 같은 토큰"을 한 줄 더했다.
- **이유**: 이 화면에서 정한 기준을 화면마다 감으로 고르지 않게 문서에 둔다. 주최 상세·아티스트 상세·검색 결과 행(`result-row` 라벨 `muted-soft`)이 같은 규칙의 적용 대상이라는 것도 적어 두었다.

### 🧭 결정 기록 (ADR)

#### 라인업 바텀시트를 없애고 카드 한 층으로 간다

- **문제**: 시트가 카드보다 더 보여주는 정보가 하루 1~2팀과 장르뿐인데, 열고 닫는 계층과 상태·dialog 코드를 유지하고 있었다.
- **선택**: 시트 삭제. 카드가 전원을 나열하고 장르를 이름 옆에 붙인다.
- **대안**:
  - 시트 유지 + 시트 안 텍스트만 키움(이슈 원안) — 코드가 그대로 남고, 사용자는 여전히 한 번 더 열어야 한다.
  - 시트 제거 + 장르도 버림 — 코드는 가장 작지만 시트가 갖던 유일한 정보를 잃는다.
- **트레이드오프**: 하루 열 팀을 넘는 축제가 들어오면 카드가 길어진다. 그때는 시트가 아니라 카드 안 접기로 간다(코드 주석으로 남김).
- ⭐ **볼트 승격 권장** — 볼트에 DEC-0158로 등록했다.

#### 히어로 스크림은 그라데이션이 아니라 단색 한 단계를 올린다

- **문제**: 밝은 포스터에서 ink 35%가 모자란다. 텍스트 블록 뒤만 진하게 덮는 하단 그라데이션 안과 단색 한 단계 상향 안이 있었다.
- **선택**: 단색. 기존 `scrim-hero`(검정 55%) 재사용.
- **대안**: 하단 그라데이션 — 포스터 상단은 더 보이지만 DESIGN.md 스크림 관례("단색, 그라데이션 아님")를 깨고 새 토큰이 필요하다.
- **트레이드오프**: 어두운 포스터는 더 어두워져 포스터 내용이 덜 보인다. 홈 히어로가 같은 값을 쓰고 있어 화면 간 일관성은 오히려 맞는다.

#### 라인업 행 링크는 이름만이 아니라 행 전체 + chevron

- **문제**: 이름만 링크로 걸면 데스크톱에서는 hover 밑줄로 알 수 있지만 모바일에서는 링크인지 알 수 없고, 터치 타깃이 글자 폭 × 21px라 44px 기준에 크게 못 미친다.
- **선택**: 행 전체를 `Link`로, 우측 chevron, hover 배경. 아티스트 목록 행과 같은 문법.
- **대안**: 이름만 링크 + hover 밑줄 — 변경은 가장 작지만 모바일 어포던스가 없고 "공개 예정"과 겉모습이 같아진다.
- **트레이드오프**: 행 높이가 늘어 375에서 카드가 하루 5팀 기준 약 30px 길어진다.
