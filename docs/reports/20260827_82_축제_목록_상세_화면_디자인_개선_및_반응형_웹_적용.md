### 📌 작업 개요

축제 목록·상세 화면이 정적으로 뚝 뜨던 것을 진입 시 부드럽게 페이드인되도록 개선했다. 목록 화면의 카드에는 hover 확대 효과를 추가했다. 반응형 레이아웃은 기존 코드가 이미 잘 갖춰져 있어 별도 수정이 필요하지 않았다.

### 🎯 구현 목표

- 축제 목록·상세 화면 진입 시 화면 전체가 뚝 뜨지 않고 부드럽게 나타나게 한다
- 상세 화면 하위 섹션은 스크롤로 들어올 때 한 번 더 페이드인되게 한다
- 목록 카드에 hover 인터랙션을 추가한다
- 좁은 화면에서도 레이아웃이 자연스럽게 대응하는지 확인한다

### ✅ 구현 내용

#### 목록 화면 진입 페이드인
- **파일**: `src/components/ui/PageFadeIn.tsx`(신규), `src/app/festivals/page.tsx`
- **변경 내용**: 화면 마운트 시점에 페이드인하는 `PageFadeIn` 컴포넌트를 만들어 목록 화면 전체를 감쌈. rAF 두 번으로 초기 상태가 한 프레임 페인트된 뒤에 전환이 시작되도록 함
- **이유**: nav·footer의 "축제" 링크로 들어오는 화면이 즉시 뚝 뜨는 대신 자연스럽게 나타나게 하기 위함

#### 상세 화면 진입·스크롤 페이드인
- **파일**: `src/app/festivals/[id]/page.tsx`, `src/components/ui/FadeInSection.tsx`(신규)
- **변경 내용**: 상세 화면 전체를 `PageFadeIn`으로 감싸 카드 클릭으로 들어올 때 부드럽게 나타나게 하고, 히어로 아래 라인업·입장 안내·오시는 길 섹션은 `IntersectionObserver` 기반 `FadeInSection`으로 감싸 스크롤 진입 시 한 번 더 페이드인되게 함
- **이유**: 히어로만 즉시 보이고 그 아래는 스크롤해야 나타나는 게 기존 구조였는데, 히어로 자체도 뚝 떠서 화면 전환이 부자연스러웠다

#### 카드 hover 확대 효과
- **파일**: `src/features/festivals/components/FestivalCard.tsx`
- **변경 내용**: hover 시 포스터가 살짝 확대되며(`scale-105`) 그림자(`shadow-hover`)가 뜨도록 추가
- **이유**: 정적인 카드 그리드에 마이크로 인터랙션을 더해 화면이 반응하는 느낌을 준다

### 🧭 결정 기록 (ADR)

#### FadeInSection·PageFadeIn을 develop에서 독립적으로 재생성
- **문제**: 같은 컴포넌트를 홈 화면 PR(#81, 이슈 #80)에서 먼저 만들었는데, 이 브랜치는 그 PR이 머지되기 전에 develop에서 분기해 해당 파일이 없었다
- **선택**: develop에서 분기한 상태를 유지한 채(리베이스하지 않고) 같은 컴포넌트를 이 브랜치에도 독립적으로 다시 만들었다
- **트레이드오프**: 두 브랜치가 각각 develop에 머지될 때 파일 add/add 충돌이 날 수 있다 — 실제로 `FadeInSection.tsx`에서 주석 한 줄 표현 차이로 충돌이 발생했고, develop을 이 브랜치에 병합해 그 자리에서 해결했다(별도 커밋 없이 병합 커밋에 반영)

#### 반응형 대응은 추가 작업 없이 종료
- **문제**: 이슈 #82에 "반응형 웹 적용"이 포함돼 있어 작업 범위로 잡았었다
- **선택**: 375px 뷰포트로 히어로·입장 안내·라인업 day-card·오시는 길 섹션을 실측 확인한 결과 이미 유동 폭·그리드 브레이크포인트로 잘 짜여 있어 깨지는 지점이 없었다 — 별도 수정 없이 반응형 항목을 충족된 것으로 결론
- **트레이드오프**: 없음 — 실제로 문제가 없었다
