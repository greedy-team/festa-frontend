### 📌 작업 개요

아티스트 목록·상세 화면을 카드 그리드 중심에서 텍스트·기록 중심 레이아웃으로 다시 짰다. 실사진을 안 쓰는 정책(DEC-0063)에 맞춰 이니셜 아바타를 목록·상세 양쪽에서 걷어내고, 좁은 화면에서의 필터 UI를 정리했다. 상세 화면은 예정 공연을 포스터 카드 가로 스크롤로, 출연 이력을 세로 타임라인으로 바꿨다. 아티스트 이름 검색도 실제로 동작하게 만들었다.

### 🎯 구현 목표

- 목록 화면을 카드 그리드에서 행 목록으로 바꾸고, 아바타를 없앤다
- 좁은 화면에서 필터(장르·검색·정렬)가 깨지지 않고 정리돼 보이게 한다
- 상세 화면의 예정 공연·출연 이력 가독성을 개선하고, 레이아웃을 다시 짠다
- 목록·상세 화면 진입 시 부드럽게 나타나게 한다
- 아티스트 이름 검색을 실제로 동작하게 만든다

### 🧭 결정 기록 (ADR)

#### 아티스트 히어로에 이름 해시 색상 배경을 넣었다가 뺐다
- **문제**: 사진을 못 쓰는 자리를 무엇으로 채울지 — 이니셜+색 아바타를 뺀 뒤 히어로가 밋밋해 보일 수 있었다
- **선택 1(기각)**: 이름을 해시해 고른 색(`nameTint`)으로 히어로 전체 배경을 채우고 흰 글자를 얹는 안을 만들었다
- **되돌린 이유**: 사용자 피드백 — "색 배경 + 흰 글자 히어로"는 사진 없는 자리를 채우는 흔한 AI 생성 디자인 패턴처럼 보인다는 지적을 받고 걷어냄
- **최종 선택**: 흰 배경 + 기존 `Badge`(인디고) + 타이포 크기만으로 존재감을 냄 — 새 색·컴포넌트 없이 기존 토큰만 재사용
- ⭐ **볼트 승격 권장** — "사진 없는 자리를 색 배경으로 채우지 않는다"는 판단 기준은 이 화면 밖에서도 재발할 수 있는 디자인 결정이다

#### 예정 공연/출연 이력을 다른 문법으로 표현
- **문제**: 두 섹션을 같은 목록 스타일로 나란히 둘지, 다르게 만들지
- **선택**: 예정 공연은 포스터 카드 가로 스크롤(미래·행동 유도형), 출연 이력은 세로 타임라인(과거·기록형)으로 형태 자체를 다르게 함
- **대안**: 기존처럼 2컬럼 좌우 배치 + 세로 구분선 — 기각. 카드 행은 가로 스크롤 공간이 필요하고 타임라인은 세로 흐름과 맞아 나란히 둘 이유가 없어졌다
- **트레이드오프**: 전폭 스택이라 상세 화면 세로 길이가 길어진다

#### 목록·상세 화면 폭을 1200px로 고정
- **문제**: 공용 `Container`는 폭 상한이 없는 유동 폭인데, 텍스트·타임라인 위주 화면은 큰 모니터에서 한 줄이 너무 길어져 읽기 불편했다
- **선택**: 이 두 화면의 `Container`에만 `max-w-[1200px] mx-auto`를 얹었다(사용자가 최종 값 지정)
- **트레이드오프**: `Container`가 원래 "폭 상한을 두지 않는다"는 프로젝트 원칙(과거 1440px 하드코딩 실수의 반작용)과 결이 다르다 — 다만 이건 Container 자체를 바꾼 게 아니라 이 두 화면만 콘텐츠 특성(읽기용 텍스트)을 이유로 캡을 얹은 것이라 원칙과 충돌하지 않는다고 판단
- ⭐ **볼트 승격 권장** — "카드 그리드는 유동 폭, 읽기용 텍스트 화면은 캡을 둔다"는 구분 기준은 다른 화면에도 적용될 수 있다
