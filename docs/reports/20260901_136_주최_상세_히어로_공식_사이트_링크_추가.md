### 📌 작업 개요

DEC-0107이 확정한 `homepageUrl` 계약이 프론트에 반영되지 않아 주최 상세 화면에서
주최 공식 사이트로 나가는 출구가 없었다. 백엔드 `HostDetailResponse`는 이미
`homepageUrl`을 내려주고 있어 프론트만 뒤처진 상태였다. 이를 채우고, 같은 결함
(관리자 등록 URL이 검증 없이 `href`에 노출)이 있던 다른 히어로 자리도 함께 닫는다.

### 🎯 구현 목표

- `HostDetail` 타입·목 응답에 `homepageUrl` 반영 (DEC-0107이 지정한 위치)
- 주최 상세 히어로 우상단에 공식 사이트 아이콘 링크 추가
- `homepageUrl`이 http(s)일 때만 링크로 그리고, 없거나 다른 스킴이면 자리를 안 그림
- 축제 상세·아티스트 상세 히어로의 외부 링크 `href`에도 `safeHttpUrl` 가드 적용

- **이유**: DEC-0107이 이름·위치·널 허용까지 지정했다. 백엔드 응답과 정합을 맞춘다

#### 주최 상세 히어로 공식 사이트 링크

- **파일**: `src/features/hosts/components/HostHero.tsx`
- **변경 내용**: 우상단에 `Globe` 아이콘 링크 추가. `absolute right-6 top-6`에

- **이유**: 축제 상세 히어로와 같은 패턴. 인스타그램은 이 응답 계약에 없어 자리를
  만들지 않는다 (DEC-0107)

#### 축제 상세 히어로 링크 href 가드

- **파일**: `src/features/festivals/components/FestivalHero.tsx`
- **변경 내용**: 주최 인스타그램·공식 사이트 링크의 조건·`href`를 `safeHttpUrl` 통과
  결과(`safeInstagramUrl`·`safeHomepageUrl`)로 교체
- **이유**: DEC-0107이 「부정적 결과」로 지목한 지점 — 관리자가 등록한 검증 안 된 URL이
  그대로 `href`에 노출되던 자리. `HostHero`만 고치지 않고 같은 결함을 소급 적용

#### 아티스트 상세 히어로 인스타그램 링크 가드 (코드리뷰 반영)

  형식 검사를 안 해 조건이 동일하다. 코드리뷰에서 지적돼 이 PR에서 함께 닫았다

#### DESIGN.md 서술 갱신

- **파일**: `.claude/rules/DESIGN.md`
- **변경 내용**: Host Detail 히어로 서술에 공식 사이트(`homepageUrl`) 링크 반영
- **이유**: 구현·타입과 문서를 한 줄씩 대조 가능하게 유지

### 🧭 결정 기록 (ADR)

#### `HostHero` 범위를 넘어 `FestivalHero`·`ArtistHero`까지 가드 적용

- **문제**: 이 이슈의 범위는 주최 상세 히어로였지만, 같은 「검증 안 된 URL을 `href`에
  직접 꽂는」 결함이 축제·아티스트 히어로에도 있었다
- **선택**: 세 히어로 모두 `safeHttpUrl` 통과로 통일. `FestivalHero`는 이 PR에서,
  `ArtistHero`는 코드리뷰 반영으로
- **대안**: 범위 밖은 후속 이슈로 분리 — 검증 없는 `href`가 남는 기간이 생긴다.
  가드는 한 줄이라 분리 비용이 오히려 크다
- **트레이드오프**: PR이 이슈 범위보다 넓어졌다. 대신 `href={...Url}` 자리가
  코드베이스에서 전부 `safe*` 변수를 거치게 정리됐다

### 🔧 주요 변경사항 상세

#### safeHttpUrl 패턴

`src/lib/safeUrl.ts`의 순수 함수 — `^https?://` 앵커로 검사해 통과하면 원본,
아니면 `null`을 반환한다. 호출부는 `null`이면 앵커를 안 그린다. `javascript:` ·
`data:` · 프로토콜 상대 `//evil.com`을 차단한다.

**특이사항**:
- 세 히어로의 가드 코드가 문자 단위로 동일하다 (`const safeXxxUrl = url ? safeHttpUrl(url) : null`)
- 링크가 없을 때 `absolute right-6 top-6` 슬롯이라 빈 원·여백·레이아웃 시프트가 남지 않는다
- 아이콘 전용 링크에 `aria-label` 부착
