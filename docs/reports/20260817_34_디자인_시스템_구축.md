# 디자인 시스템 구축 — 토큰·공용 컴포넌트·레이아웃 셸

### 📌 작업 개요

`.claude/rules/DESIGN.md`를 코드로 옮겨 화면 작업의 기반을 만들었다. 디자인 토큰, 폰트, 아이콘, 공용 컴포넌트 5개, 레이아웃 셸, 그리고 이것들을 눈으로 대조할 전시 화면 `/showcase`까지 한 브랜치에서 처리했다.

PR #37로 `develop`에 머지됐다.

### 🎯 구현 목표

- DESIGN.md의 색·타이포·radius·그림자를 전역 토큰으로 선언
- Geist를 Pretendard로 교체
- 명세 13종을 컴포넌트 5개로 축약
- Container·Header·Footer를 RootLayout에 적용
- `/showcase` 한 경로에서 모든 변형을 시안과 대조 가능하게

### ✅ 구현 내용

#### 패키지 추가

- **파일**: `package.json`
- **변경 내용**: `lucide-react`, `pretendard` 추가
- **이유**: DESIGN.md가 "아이콘 시스템이 없다"고 직접 적어 둔 자리이고, 남은 화면까지 보면 아이콘 15~20개가 필요하다. Pretendard는 문서가 명시한 글꼴인데 실제 코드는 Geist였다

#### 디자인 토큰

- **파일**: `src/app/globals.css`
- **변경 내용**: `@theme` 블록에 색 34 · 타이포 26 · radius 12 · 그림자 2를 선언. `--color-*: initial`, `--radius-*: initial`로 Tailwind 기본값을 먼저 지운다
- **이유**: 기본 팔레트를 남겨 두면 `bg-blue-500` 같은 시안 밖 색이 아무 저항 없이 들어온다. 문서 규칙을 기계 제약으로 바꾸는 것이 목적이다

색 34는 시스템 색 25 + 포스터 틴트 9다. 리셋 뒤 `transparent`·`currentColor`·`inherit`·`white`·`black` 5개만 되살렸다. 타이포 토큰은 하나에 크기·행간·굵기가 함께 실려 `text-hero-dday` 한 클래스로 56/700/1.21이 결정된다.

#### 폰트 교체

- **파일**: `src/app/globals.css`, `src/app/layout.tsx`
- **변경 내용**: Geist 제거, Pretendard Variable dynamic-subset 셀프호스팅
- **이유**: dynamic-subset은 브라우저가 실제로 쓰는 글자만 내려받는다. 한글 전체 웨이트를 통째로 받지 않는다

#### 공용 컴포넌트 5종

- **파일**: `src/components/ui/{Button,Badge,Chip,SearchPill,InlineFilter}.tsx`
- **변경 내용**: DESIGN.md 명세 13종을 축으로 분해해 5개 파일로 구현
- **이유**: 버튼 5종은 색 3가지 × 높이 3가지의 조합이고 뱃지 4종은 색만 다르다. 명세를 1:1로 옮기면 같은 것이 여러 벌 생긴다

폭은 컴포넌트 속성이 아니라 사용처가 정한다. 시안에서 같은 `button-primary`가 180×48이기도 하고(`search-filter-panel`의 「검색하기」는) 160×52이기도 하다.

#### 레이아웃 셸

- **파일**: `src/components/layout/{Container,Header,Footer}.tsx`, `src/app/layout.tsx`
- **변경 내용**: 폭 상한 없는 유동 Container, Header·Footer를 RootLayout에 적용
- **이유**: 시안의 1440 프레임은 구상이지 계약이 아니다. `max-w-[1440px]`로 박으면 2560 모니터에서 양쪽이 빈다

#### 전시 화면

- **파일**: `src/app/showcase/**`
- **변경 내용**: 토큰 견본과 컴포넌트 전 변형을 6개 페이지로 전시
- **이유**: 리뷰어가 경로 하나만 열면 시안과 눈으로 대조할 수 있다. 표시 전용 컴포넌트의 검증을 단위 테스트 대신 이 화면이 맡는다

### 🧭 결정 기록 (ADR)

#### Tailwind 기본 팔레트·radius를 리셋

- **문제**: 토큰을 추가만 하면 `bg-blue-500`, `rounded-xl` 같은 시안 밖 값이 그대로 살아 있다
- **선택**: `--color-*: initial`, `--radius-*: initial`로 네임스페이스를 비우고 DESIGN.md 값만 다시 채운다
- **대안**:
  - 토큰만 추가 — 규칙이 문서에만 있고 코드가 강제하지 않는다. 리뷰에서 매번 잡아야 한다
  - ESLint 규칙으로 금지 — 클래스 문자열을 정적 분석해야 해서 비용이 크고 동적 조합을 못 잡는다
- **트레이드오프**: Tailwind 예제를 그대로 붙여넣으면 색이 안 먹는다. 처음 보는 사람이 당황할 수 있어 `globals.css` 상단에 이유를 적었다
- ⭐ **볼트 승격 권장** — 되돌리는 비용이 크고 이후 모든 화면 작업에 걸린다

#### 폭은 유동, 높이는 시안 리터럴

- **문제**: 시안 충실도를 위해 폭까지 리터럴로 박으면 곧 해상도 잠금이 된다. 실제로 첫 구현이 `Container`를 `max-w-[1440px] px-20`, 검색 pill을 `w-[320px]`, 색 견본을 `grid-cols-6`으로 박아 브레이크포인트가 0개였다
- **선택**: 레이아웃 폭은 유동(`w-full` / `w-[…] max-w-full` / `grid-cols-*`), 컴포넌트 높이·아이콘 크기는 시안 리터럴
- **대안**: 전 구간 리터럴 — 시안 대조는 쉽지만 2560에서 양쪽이 비고 좁은 화면에서 넘친다
- **트레이드오프**: 시안과 픽셀 단위로 겹쳐보는 검수가 1440에서만 가능하다
- ⭐ **볼트 승격 권장** — 이후 20여 개 컴포넌트가 전부 이 규칙 위에 올라간다

#### 버튼 폭을 컴포넌트가 갖지 않는다

- **문제**: DESIGN.md가 `button-primary`를 180×48로 이름 붙였는데, 같은 문서의 `search-filter-panel`은 같은 primary를 160×52로 쓴다
- **선택**: `variant`(색)와 `size`(높이)만 컴포넌트가 갖고, 폭은 호출부가 `className`으로 준다
- **대안**: 명세 5종을 유니온으로 못박기 — 문서 자체가 이미 6번째 조합을 쓰고 있어 첫 화면에서 깨진다
- **트레이드오프**: 타입만 보고는 어느 조합이 시안에 있는지 알 수 없다. 화면이 몇 개 나와 실제 조합이 드러난 뒤 화이트리스트를 만드는 것이 순서다

#### MVP에 없는 요소를 링크가 아닌 `<span>`으로

- **문제**: 헤더의 벨·북마크·프로필과 푸터 링크 7개는 로그인을 전제하거나 화면이 아직 없다. 링크로 만들면 데모 중 404가 난다
- **선택**: 시안대로 그리되 `<span>`으로 둔다. 조건부 렌더는 `&&`가 아니라 삼항으로 써서 "링크가 아닐 때 무엇이 되는가"를 빼먹을 수 없게 한다
- **대안**: 항목을 지우기 — 시안과 어긋나고 사라진 이유가 코드에 남지 않는다
- **트레이드오프**: 로그인이 붙을 때 이 자리를 다시 찾아야 한다. 주석에 스펙 절 번호를 적어 두었다

이슈 단계에서 이미 확정한 결정(shadcn/ui 미도입, 태블릿 이하 미대응, 아이콘은 lucide-react)은 이슈 본문에 근거가 남아 있어 여기서 반복하지 않는다.

### 🔧 주요 변경사항 상세

#### globals.css

`@theme` 한 블록이 토큰의 단일 출처다. 타이포는 `--text-<이름>`과 짝이 되는 `--line-height`, `--font-weight`를 함께 선언해 클래스 하나로 세 값이 결정된다. line-height는 DESIGN.md대로 전 스케일 1.21 고정이다.

**특이사항**:

- `--color-body-text`는 DESIGN.md의 `colors.body`인데 이름을 바꿨다. `--color-body`로 두면 타이포 토큰 `text-body`와 클래스 이름이 충돌한다
- spacing 토큰은 두지 않았다. DESIGN.md의 10종(4·8·12·16·20·24·32·40·64·80)이 Tailwind 기본 4px 스케일과 정확히 일치해서 `p-8`·`gap-6`이 그대로 시안 값이다

#### Header.tsx

로고와 메뉴 사이를 `gap-4 sm:gap-8 lg:gap-16`으로 벌린다. 시안의 로고→첫 메뉴 거리는 1440 프레임에서의 한 사례일 뿐이라 고정하지 않는다.

활성 메뉴 인디케이터는 글자 폭과 같은 너비 × 2px이다. `after:w-full`이 그 역할을 하고, `aria-current="page"`로 보조기술에도 현재 위치를 전달한다.

#### Button.tsx

`px-6`과 `cursor-pointer`가 DESIGN.md에 없는 기본값이다. 시안은 버튼마다 폭을 고정값으로 주므로 패딩이 명시되지 않았고, 커서는 Tailwind 4가 preflight에서 button을 브라우저 기본값(화살표)으로 두기 때문에 필요하다. v3까지는 자동이었다.
