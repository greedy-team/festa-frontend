### 📌 작업 개요

다가오는 축제가 0건일 때 홈 히어로의 빈 배경을 실제 아티스트 이름으로 채우고, 스크롤에 따라 이름 벽이 축소·이동·페이드되도록 구현했다. 예정 축제가 있으면 기존 축제 카드 캐러셀을 그대로 사용하며, 카드 사이에 보이던 흰색 경계선도 함께 제거했다.

**보고서 파일**: `docs/reports/20260906_178_홈_히어로_빈_상태_아티스트_이름_벽과_스크롤_모션.md`

### 🎯 구현 목표

- 다가오는 축제가 없을 때 빈 상태를 실제 아티스트 데이터로 구성
- 스크롤 시 배경만 자연스럽게 이동하고 핵심 안내 문구와 CTA는 유지
- 동작 줄이기 설정과 키보드 접근성 보장
- 예정 축제가 있을 때 카드 캐러셀의 흰색 경계선 제거

### ✅ 구현 내용

#### 빈 상태에서만 아티스트 조회

- **파일**: `src/app/page.tsx`
- **변경 내용**: 예정 축제 조회가 성공하고 결과가 0건일 때만 아티스트 50팀을 출연 횟수순으로 조회
- **이유**: 축제 카드가 표시되는 평상시에는 사용하지 않는 요청을 보내지 않기 위함
- **실패 처리**: 아티스트 조회 실패 또는 빈 결과는 기존 메시 배경으로 대체

#### 실제 아티스트 이름 벽 구성

- **파일**: `src/features/home/components/Hero.tsx`
- **변경 내용**: 이름별 크기와 불투명도를 순환 배치하고, 중앙에는 안내 문구가 읽히도록 기존 히어로 색상의 방사형 오버레이 적용
- **접근성**: 장식용 이름 벽은 `aria-hidden`과 `pointer-events-none` 적용. CTA는 `/artists`로 연결
- **검증 코드**: `wallNameClass`가 모든 인덱스에서 유효한 Tailwind 클래스 조합을 반환하는 유닛 테스트 추가

#### 스크롤 반응 애니메이션

- **파일**: `src/features/home/components/Hero.tsx`, `src/components/ui/FadeInSection.tsx`, `e2e/home-scroll-motion.spec.ts`
- **변경 내용**: 스크롤 진행도에 따라 이름 벽을 1.06배에서 0.94배로 축소하고 아래로 최대 80px 이동하며 불투명도를 1에서 0.35까지 낮춤. 첫 콘텐츠 섹션은 16px 이동·350ms 페이드인 적용
- **상호작용**: 스크롤 시작 후 아래 방향 힌트를 숨기고 `inert`로 포커스 대상에서도 제외
- **접근성**: `prefers-reduced-motion: reduce`에서는 이름 벽 변형과 전환을 제거하고 스크롤 힌트 이동을 즉시 처리

#### 축제 카드 사이 흰색 경계선 제거

- **파일**: `src/features/home/components/HeroPanel.tsx`
- **변경 내용**: 카드 내부 링크의 시각 영역만 1px 넓혀 소수점 단위 슬라이드 폭에서 생기는 렌더링 틈을 덮음
- **영향 범위**: 바깥 슬라이드 폭과 캐러셀 이동 거리는 유지

### 🧭 결정 기록 (ADR)

#### 아티스트 조회는 빈 상태에서만 실행

- **문제**: 아티스트 목록을 예정 축제 요청과 항상 병렬 호출하면 축제 카드가 있는 화면에서도 불필요한 요청 발생
- **선택**: 예정 축제 0건을 확인한 뒤 아티스트 API 호출
- **트레이드오프**: 빈 상태에서는 요청이 순차 실행되어 히어로 데이터 준비가 한 단계 늦어짐

#### 스크롤 애니메이션은 이름 벽에만 적용

- **문제**: 히어로 전체를 움직이면 안내 문구와 CTA까지 흐려져 사용자가 다음 행동을 놓칠 수 있음
- **선택**: 배경 이름 벽만 축소·이동·페이드하고 중앙 콘텐츠는 고정
- **트레이드오프**: 스크롤 위치를 계산하는 가벼운 클라이언트 효과가 추가됨. `requestAnimationFrame`으로 프레임당 한 번만 반영

#### 1px 겹침으로 카드 경계선 제거

- **문제**: 화면 폭을 3등분하거나 4등분할 때 소수점 픽셀 반올림으로 카드 사이에 배경색이 흰 선처럼 노출
- **선택**: 캐러셀 계산에 쓰이는 슬라이드 폭은 유지하고 내부 시각 영역만 1px 확장
- **트레이드오프**: 인접 카드 위로 1px 겹치지만 카드 배치와 이동 거리는 바뀌지 않음

### 🔧 주요 변경사항 상세

- 예정 축제 0건: 아티스트 수와 이름 벽, 안내 문구, 아티스트 목록 CTA 표시
- 예정 축제 1건 이상: 기존 축제 카드 히어로와 자동 재생 캐러셀 유지
- 아티스트 API 실패: 빈 이름 벽 대신 기존 메시 배경 표시
- 스크롤 복원·화면 크기 변경: 현재 히어로 위치를 다시 계산해 애니메이션 상태 동기화
- 첫 콘텐츠 섹션: 헤더에 가리지 않도록 스크롤 여백 유지
