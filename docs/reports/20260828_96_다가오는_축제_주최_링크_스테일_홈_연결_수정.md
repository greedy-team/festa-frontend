### 📌 작업 개요

과거 대상 화면이 아직 없어 "임시로 홈에 연결한다"고 남겨둔 링크 2곳을, 실제 화면이 머지된 뒤에도 고치지 않은 채 남아 있던 것을 수정했다. #94(접근성 점검) 작업 중 발견한 별개의 버그다.

### 🔍 문제 분석

주최 상세 화면의 "다가오는 축제" 카드와 축제 상세 화면의 "주최" 링크가 각각 "자세히 보기 →", "주최 · 학교명 ›"이라고 표시하면서 실제로는 `href="/"`(홈)로 연결돼 있었다.

- `UpcomingFestivalCard.tsx`: "축제 상세(#45)가 develop에 아직 없어 임시로 홈에 연결한다"는 주석이 남아 있었지만, 축제 상세는 이미 머지되어 `/festivals/{id}`로 접근 가능한 상태였다
- `FestivalHero.tsx`: "주최 상세(DESIGN.md 10 School Detail, #46)가 아직 없어 임시로 홈에 연결한다"는 주석이 남아 있었지만, 주최 상세도 이미 `/hosts/{id}`로 구현돼 있었다

같은 패턴의 스테일 링크가 아티스트 상세 화면의 "예정 공연" 카드에서도 있었고 이미 실제 축제 상세로 수정된 바 있다 — 대상 화면이 하나씩 머지될 때마다 "임시 연결"로 남겨뒀던 링크들이 그때그때 갱신되지 않고 누락되는 패턴이 반복되고 있었다.

### ✅ 구현 내용

#### 주최 상세 "다가오는 축제" 카드 링크 수정
- **파일**: `src/features/hosts/components/UpcomingFestivalCard.tsx`
- **변경 내용**: `href="/"` → `href={`/festivals/${festivalId}`}`
- **이유**: 카드가 표시하는 응답 필드(`UpcomingHostFestival.festivalId`)로 실제 축제 상세를 바로 가리킬 수 있었다

#### 축제 상세 "주최" 링크 수정
- **파일**: `src/features/festivals/components/FestivalHero.tsx`
- **변경 내용**: `href="/"` → `href={`/hosts/${host.id}`}`
- **이유**: 히어로가 이미 받고 있는 `FestivalHostSummary.id`로 실제 주최 상세를 바로 가리킬 수 있었다
