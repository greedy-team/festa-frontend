# 헤더 nav 메뉴에 hover 시 글씨 확대 효과 추가

## 📌 작업 개요

데스크톱 헤더의 nav 메뉴(홈·축제·아티스트)는 hover 시 글자 색만 바뀌어 시각 피드백이
약했다. 마우스를 올리면 글씨가 확대되며 반응하는 효과를 추가한다.

관련 이슈: #216

## 🎯 구현 목표

- 데스크톱 nav 3개 항목에 hover 시 글씨 확대
- 확대해도 인접 메뉴·활성 밑줄이 밀리지 않을 것
- prefers-reduced-motion에서는 확대를 끌 것 (색 전환은 유지)
- 히어로 위(투명 헤더) 상태에서도 자연스러울 것

## ✅ 구현 내용

### nav 링크 클래스에 hover 확대 추가

- 파일: `src/components/layout/Header.tsx`
- 변경 내용: 데스크톱 `<nav>`의 `linkClassName`(active·inactive 양쪽)에서
  `transition-colors` → `transition`으로 바꾸고 `hover:scale-[1.15]`,
  `motion-reduce:hover:scale-100`을 추가.
- 이유: `transition`이 색과 크기를 함께 300ms로 전환한다. 동작 줄이기에서는
  `hover:scale-100`이 확대만 무효화하고 색 전환은 그대로 둔다.

## 🧭 결정 기록 (ADR)

### hover 확대를 font-size가 아니라 scale transform으로

- 문제: "글씨가 커진다"를 font-size로 구현하면 hover 시 요소의 레이아웃 박스가
  커져 옆 메뉴가 밀리고, 활성 메뉴의 밑줄(`after:w-full`)이 매번 다시 계산된다.
- 선택: `hover:scale-[1.15]` — transform은 레이아웃 박스를 바꾸지 않아 이웃이
  움직이지 않는다. transform-origin은 기본값(center)이라 좌우로 균등하게 커진다.
- 대안:
  - font-size 변경 (`hover:text-lg` 류) — reflow 발생. 요구사항 위반.
  - 표준 스케일 `scale-110` — "조금 더 크게" 요청에 맞춰 `[1.15]`로 조정.
- 트레이드오프: 카드 hover(`group-hover:scale-105`)는 표준값을 쓰는데 여기만
  임의값(`[1.15]`)이 됐다. nav 텍스트용으로 튜닝한 값이라 코드 주석에 근거를 남겼다.
- 참고: 이 규칙(hover 확대는 transform)은 재사용 가치가 있어 `/capture` 후보다.

### 동작 줄이기에서 transition-none 대신 hover:scale-100

- 문제: 헤더의 색 전환(투명↔솔리드, 300ms, DEC-0128)이 이미 모든 사용자에게
  적용돼 있다. `motion-reduce:transition-none`을 넣으면 이 색 전환도 즉시로 바뀐다.
- 선택: `motion-reduce:hover:scale-100`만 추가. 확대는 꺼지고(hover 상태 == 기본
  상태라 전환할 것이 없다) 기존 색 전환 동작은 변하지 않는다.
- 대안: `motion-reduce:transition-none` — #94의 25곳 관례와 일치하지만, 이 작업
  범위(hover 확대 추가)를 넘어 헤더 색 전환 동작까지 바꾼다.

## 🔧 주요 변경사항 상세

### Header.tsx

active / inactive 두 분기 모두 `transition duration-300 hover:scale-[1.15]
motion-reduce:hover:scale-100`을 공유한다. `after:transition-colors
after:duration-300`(활성 밑줄 색)은 그대로 두었다.

특이사항:
- 모바일 드롭다운 메뉴에는 적용하지 않았다 — 터치에는 hover가 없고, 전폭 행이라
  텍스트 확대가 어색하다.
- "Claude in Chrome" 자동화 브라우저는 CSS `:hover` 상태를 실제로 만들지 못해
  (기존 카드 zoom도 같은 한계) 검증이 불가능했다. 프로젝트 e2e 도구인
  Playwright(실 Chromium)로 확인했다.

  - "아티스트" hover 시 `getComputedStyle().scale`가 `1.15`
  - 같은 시점 이웃 "홈"의 x좌표가 543.59 → 543.59 (밀리지 않음)
  - `emulateMedia({ reducedMotion: "reduce" })`에서 hover 시 `scale`가 `1`

## 📌 참고사항

- 기존 reduced-motion e2e(`e2e/reduced-motion.spec.ts`)는 "애니메이션이 꺼져도
  콘텐츠가 남는가"를 보는 것이라 hover 마이크로 인터랙션은 대상이 아니다. 이
  확대 동작을 회귀로 고정하려면 별도 e2e를 추가할 수 있다(현재는 미추가).
- DESIGN.md는 상호작용 상태를 Default / Active / Hover(그림자만)로만 정의한다.
  nav 글씨 확대는 시스템에 없는 상호작용이라 디자이너 검토 여지가 있다.
