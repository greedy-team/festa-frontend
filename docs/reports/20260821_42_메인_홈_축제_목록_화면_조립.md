### 📌 작업 개요
홈 화면을 placeholder에서 06-D 시안(4분할 히어로 캐러셀)으로 조립하고, 축제 목록(`/festivals`) 화면을 새로 만들었다. 두 화면이 공유하는 카드·정렬·페이지네이션 컴포넌트도 함께 정리했다.

### 🎯 구현 목표
- 홈: 히어로 캐러셀 → 최근 등록된 축제 → 분실물 패널 + 광고 슬롯 순서로 06-D 시안 재현
- 축제 목록: 브레드크럼 → 검색/정렬 → 카드 그리드 → 페이지네이션 → 광고 배너

### 🧭 결정 기록 (ADR)

#### 실패와 "0건"을 구분한다
- **문제**: `upcomingRes`/`recentRes`가 실패해도 빈 배열로 떨어져 "서버가 죽었는지" "축제가 없는지"를 화면에서 구분할 수 없었다
- **선택**: `res.ok`로 먼저 갈라 실패 시 콘솔 로그 + 별도 안내 문구, 성공인데 0건일 때만 "없습니다" 문구
- **트레이드오프**: 분기가 하나 늘지만 `lib/api.ts`가 원래 의도한 설계(404/500과 "0건"을 다르게 보여준다)를 지킨다

#### 목적지 없는 카드는 링크를 그리지 않는다
- **문제**: 축제 상세 화면이 아직 없는 시점에 `FestivalCard`를 `href="/"`로 임시 연결하면, 클릭 시 홈으로 튕기고 스크린리더에도 유효 링크로 읽힌다
- **선택**: 저장소에 이미 있던 관례(`Footer`/`SectionHeaderRow`/`RecentCard`)를 따라 `<article>`로 두고 목적지가 생기면(축제 상세 PR #45) 그때 `Link`로 승격
- **대안**: 임시로 홈에 연결 — 시각적으로는 동작하지만 잘못된 어포던스를 남긴다

#### `not-found.tsx`/`error.tsx` 신규 추가
- **문제**: Next.js 기본 404/500 화면이 영어 문구 + 검은 배경으로 떠서 브랜드 셸(nav/footer)과 어긋났다
- **선택**: `Container` 기반의 한글 커스텀 화면 추가

### 🔧 주요 변경사항 상세

#### `/festivals` 페이지네이션·정렬
`?page=` 파라미터에 `Math.floor` 가드를 둬서 소수(`2.5`)가 그대로 API로 나가 400이 되는 것을 막았고, 요청 페이지가 총 페이지 수를 넘으면 마지막 페이지로 다시 조회한다. `Pagination`의 `makeHref`는 현재 쿼리를 `URLSearchParams`로 먼저 복사한 뒤 `page`/`sort`만 덮어써서, 나중에 `q`나 `artistId` 같은 파라미터가 붙어도 페이지 이동 시 사라지지 않는다.

**특이사항**:
- 5-up 그리드는 `grid-cols-2 sm:grid-cols-3 lg:grid-cols-5`로 반응형 처리 — 초기 구현은 `grid-cols-5` 고정이라 375px에서 카드가 55px까지 줄어드는 문제가 있었다
