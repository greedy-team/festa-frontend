### 📌 작업 개요

검색 노출 기반 배포 후 Google Search Console 등록과 사이트맵 제출을 완료했다. 네이버 서치어드바이저 소유확인을 위한 메타태그를 추가했고, 홈 히어로의 첫 번째 배경색을 디자인 문서와 실제 CSS에 동일하게 반영했다.

기존 SEO·공유 이미지·광고 구현 보고서는 유지하고, 이 문서에는 검색엔진 등록 현황과 후속 변경만 정리했다.

### 🎯 구현 목표

- Google과 네이버에서 운영 사이트 소유권 확인
- 운영 사이트맵 제출과 색인 가능 상태 점검
- 네이버 소유확인 메타태그를 모든 페이지의 `<head>`에 제공
- 홈 히어로 배경색과 디자인 토큰의 불일치 해소

### ✅ 구현 내용

#### 네이버 사이트 소유확인 메타데이터

- **파일**: `src/app/layout.tsx`
- **변경 내용**: Next.js 루트 `metadata.verification.other`에 `naver-site-verification` 항목을 추가했다. 인증 문자열은 `{TOKEN}`으로 마스킹한다.
- **이유**: 전체 공개 페이지의 `<head>`에 동일한 소유확인 태그를 지속적으로 제공하기 위해서다.

메타태그 값은 사이트 소유확인에 사용되며 계정 접근 권한을 제공하는 비밀 정보가 아니다. 다만 보고서에는 실제 값을 기록하지 않는다.

#### 히어로 배경색 조정

- **파일**: `src/app/globals.css`, `.claude/rules/DESIGN.md`
- **변경 내용**: 첫 번째 히어로 틴트를 `#1e3a5f`에서 `#315f7d`로 바꾸고 CSS 토큰과 디자인 문서의 값을 동기화했다.
- **이유**: 첫 히어로 패널의 배경색을 조정하면서 구현과 디자인 정보가 서로 다르게 남지 않도록 하기 위해서다.

#### 기존 구현 보고서 보존

- **파일**: `docs/reports/20260907_201_SEO_공유_이미지_광고_적용.md`
- **변경 내용**: SEO 메타데이터, robots, sitemap, 공유 자산, 광고 소재 구현 내용을 담은 기존 보고서를 별도 기록으로 유지했다.
- **이유**: 전체 구현 내용과 배포 후 운영 작업을 구분해 중복을 줄이고 변경 흐름을 보존하기 위해서다.

### 🧭 결정 기록 (ADR)

#### 네이버 소유확인을 루트 메타데이터로 관리

네이버가 지원하는 HTML 파일 업로드 대신 Next.js 루트 메타데이터에 소유확인 태그를 추가했다. 별도 정적 파일을 관리하지 않고 기존 메타데이터 정의 위치에서 사이트 전체에 일관되게 적용할 수 있다.

### 🔧 주요 변경사항 상세

#### 검색엔진 등록 현황

- Google Search Console에 Domain 속성 `every-festa.com` 소유권 확인 완료
- Google Search Console에 `https://www.every-festa.com/sitemap.xml` 제출 완료
- 네이버 서치어드바이저 사이트 등록 완료
- 네이버 소유확인은 메타태그가 Production에 배포된 뒤 진행 예정

#### Production 색인 기반 점검

- 홈, `/robots.txt`, `/sitemap.xml` HTTP 200 확인
- 홈 문서에 `noindex` 없음
- 홈 응답에 `X-Robots-Tag` 없음
- 사이트맵 XML 형식 유효성과 공개 URL 390개 포함 확인
- Open Graph 이미지, favicon, 주요 공개 페이지 HTTP 200 확인

- 해당 커밋을 push하고 Production 배포를 확인한 뒤 네이버 소유확인과 사이트맵 제출을 진행해야 한다.
