# QA 체크리스트

데모데이 요구사항 중 "QA 시트" 항목 대응 문서. 실제 코드(2026-08-30 기준)를
기준으로 화면·기능별 수동 확인 항목을 정리했다. E2E 테스트(Playwright)가
이미 자동으로 검증하는 흐름은 겹치지 않게 최소화하고, 사람이 눈으로만
확인할 수 있는 것(시각적 디자인, 크로스브라우저, 반응형, 의도된 빈 상태 등)
위주로 담았다.

사용법: 화면마다 브라우저/폭 조합으로 한 번씩 돌며 체크한다. `⚠️`가 붙은
항목은 버그 리포트 대상이 아니라 "문서·기획과 실제 구현이 다르다"는 걸
미리 알려주는 참고용이다 — 발견해도 이슈로 올리지 말고 팀에 공유부터 한다.

## 0. 공통 (환경)

- [ ] Chrome 최신, Edge 최신, Safari 최신, 삼성인터넷 최신에서 각각 열어봤다 (DEC-0104 지원 범위)
- [ ] 데스크톱(1440) / 랩탑(1280) 폭에서 레이아웃이 안 깨진다 (모바일은 대상 아님 — DEC-0103)
- [ ] 새로고침 시 헤더가 투명→불투명으로 튀지 않는다 (스크롤 위치 복원 케이스)
- [ ] 이미지(포스터 등) 로드 실패 시 깨진 아이콘 대신 틴트/플레이스홀더가 뜬다
- [ ] sm~lg(640~1024) 사이에서 nav 검색창이 안 보이는 게 정상이다 — 로그인 없이는 640px 미만에서 햄버거로 전환
- [ ] 벨·북마크·프로필 아바타 아이콘은 없는 게 정상이다 — "로그인을 전제하는 MVP 이후 기능이라 뺐다"는 주석이 코드에 있음. 버그 아님

## 1. 홈 (`/`)

- [ ] 히어로 캐러셀이 자동 재생되고, 화살표/도트로 수동 넘기기가 된다
- [ ] 히어로 패널 클릭 → 해당 축제 상세로 이동한다
- [ ] "최근 등록된 축제" 카드 5개가 정상 노출되고 클릭 시 상세로 이동한다
- [ ] 축제가 0건일 때 대체 문구/바로가기(퀵링크)가 뜬다 (방학 등 비수기 케이스)
- [ ] "최근 분실물" 패널이 "아직 등록된 분실물이 없습니다" 빈 상태로 뜬다 — 분실물 API 자체가 미구현이라 항상 이 상태가 맞음(버그 아님)
- [ ] 광고 슬롯이 "AD" 라벨과 함께 자리 잡고 있다

## 2. 축제 목록 (`/festivals`)

- [ ] 정렬(최신순/다가오는 순) 변경 시 목록이 실제로 바뀐다
- [ ] 페이지네이션이 마지막 페이지까지 정상 동작한다
- [ ] 검색 pill은 아직 클릭이 안 된다(표시 전용) — 오조작으로 오해하지 않는지 확인
- [ ] 필터 결과 0건일 때 에러 화면이 아니라 "등록된 축제가 없습니다"가 뜬다 (#119에서 고친 부분, 재발 여부)
- [ ] 하단 배너형 광고 슬롯이 노출된다

## 3. 축제 상세 (`/festivals/[id]`)

- [ ] D-day, 날짜, 장소, 티켓 정보가 정확히 표시된다
- [ ] 진행중(ONGOING) 상태일 때만 "진행중" 배지가 뜬다 (예정·종료는 배지 없이 D-day 텍스트만)
- [ ] 라인업 DAY별 카드가 보이고, "전체 라인업 보기"로 바텀시트가 열린다
- [ ] 미공개(`revealed:false`) 아티스트가 "공개 예정"으로 흐리게 표시된다
- [ ] 주최 pill 클릭 → 주최 상세로 이동한다
- [ ] 오시는 길 지도 자리가 플레이스홀더로라도 노출된다 (실제 지도 연동 전)
- [ ] 존재하지 않는 id로 접근 시 404 화면이 뜬다
- [ ] ⚠️ **광고 슬롯 없음** — DESIGN.md엔 "오시는 길 옆에 광고 슬롯"이라고 적혀 있지만 실제 코드(`festivals/[id]/page.tsx`)엔 `AdSlot`이 없다. 의도된 축소인지 기획 확인 필요 (다른 6개 화면엔 전부 있음)

## 4. 아티스트 목록 (`/artists`)

- [ ] 검색창에 이름을 입력하면 결과가 실제로 좁혀진다
- [ ] 장르 칩 필터가 동작한다
- [ ] 페이지네이션이 정상 동작한다
- [ ] 모바일 폭(반응형 축소 시)에서도 검색·필터가 정상 노출된다

## 5. 아티스트 상세 (`/artists/[id]`)

- [ ] 예정 공연 카드 hover 시 잘리지 않고 자연스럽게 확대된다 (#101/#102에서 고친 부분)
- [ ] 예정 공연 카드 클릭 → 해당 축제 상세로 이동한다
- [ ] 출연 이력이 타임라인 형태로 최신순 노출된다
- [ ] 장르가 없는 아티스트는 칩 자리가 아예 안 보인다 (빈 배지 아님)
- [ ] 인스타그램 링크가 있을 때만 아이콘이 뜬다

## 6. 주최 상세 (`/hosts/[id]`) / 축제 이력 (`/hosts/[id]/history`)

- [ ] 다가오는 축제가 0건인 학교는 섹션이 통째로 안 보이거나 빈 문구가 뜬다
- [ ] "전체 보기" 클릭 → 축제 이력 전체 화면으로 이동하고 목록이 채워진다
- [ ] 이력 페이지 페이지네이션이 정상 동작한다
- [ ] 자주 온 아티스트 순위(01~03)가 정상 표시된다 (출연 이력 없는 신생 학교는 섹션 자체가 안 보임)

## 7. 통합 검색 (`/search`)

- [ ] 검색어 없이 진입 시 "검색어를 입력해주세요" 안내가 뜬다
- [ ] 검색 결과가 축제/아티스트/학교 탭별로 정상 필터링된다
- [ ] 결과 0건일 때 "검색 결과가 없습니다"가 뜬다 (에러 화면과 구분되는지)
- [ ] 검색 결과 헤딩("검색 결과 N건")과 실제 카드 수가 일치한다

## 8. 관리자 (`/admin/*`)

- [ ] 잘못된 계정으로 로그인 시 에러 문구가 뜬다
- [ ] 정상 로그인 후 콘솔(`/admin/festivals`)로 이동한다
- [ ] `/admin` 루트로 접근하면 자동으로 `/admin/festivals`로 리다이렉트된다
- [ ] 로그아웃/토큰 없는 상태로 콘솔 직접 접근 시 로그인으로 리다이렉트된다
- [ ] 사이드바 "로그아웃" 클릭 → 토큰 삭제되고 로그인 화면으로 이동한다
- [ ] 좁은 화면(1024px 미만)에서 사이드바가 서랍(햄버거)으로 바뀌고, Esc·바깥 클릭으로 닫힌다
- [ ] 미발행 축제 발행 시 상태가 "발행됨"으로 바뀐다
- [ ] 라인업 0팀/주최 미연결 축제는 발행 시도 시 실패 사유가 명확히 뜬다

## 9. 접근성

- [ ] 키보드만으로 nav → 본문 → footer까지 탭 이동이 가능하다
- [ ] 모션 감소(reduce motion) 설정 시 캐러셀 자동재생 등 애니메이션이 줄어든다

## ⚠️ 문서-코드 불일치 (QA 발견 대상 아님, 기획 확인 대상)

DESIGN.md(디자인 시스템 문서)에는 있는데 실제 코드에는 없거나 다르게 구현된
것들. QA 중 헷갈리지 않도록 미리 정리해둔다 — 버그로 리포트하지 않는다.

- **축제 상세 광고 슬롯**: 문서엔 있음, 코드엔 없음 (위 3번 항목 참고)
- **`bottom-cta-banner` 컴포넌트**: 문서에 정의만 있고 실제 어느 화면에도 쓰이지 않음
- **`search-filter-panel`(3열×2행 필드 그리드) 컴포넌트**: 문서에 정의만 있고, 실제 `/search`는 더 단순한 탭 필터(전체/아티스트/학교/축제)로 구현됨
- **홈 히어로 요약 시트**: 카드 클릭 시 요약 시트 없이 상세로 직행하는 것으로 확정됨(DESIGN.md에 명시). Figma에 남아있는 옛 프레임과 혼동하지 않기
- **분실물(로스트 아이템) 화면 전체**: 백엔드 API 자체가 없어 목록·상세 화면이 아예 없음. 홈의 "최근 분실물" 패널만 빈 상태로 존재
